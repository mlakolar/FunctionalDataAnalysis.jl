Milestone 4 task 3: cross-covariance validation

Implemented CrossCovariance, SmoothedCrossCovariance, and cross_covariances. The dense estimator returns sample cross-covariance; the smoother reuses milestone 2's local linear regression, subject-level CV, and weight-preserving pair aggregation. It supports separate axis bandwidths. The block helper uses existing diagonal covariance fits and fits unordered cross-node pairs once. The reverse block is an independent transposed copy.

The fdapace source audit documents the 0.6.0 implementation and its differences from this API. The Smoothing page gives the public contract.

Details resolved by the implementation

  • A node's common grid need not equal the other node's common grid. Dense covariance is a rectangular sample cross-covariance without resampling.
  • Direct cross fits accept SmoothedMean or one complete grid curve as each mean. Existing SmoothedCovariance now also accepts the latter, so the helper reuses task 1 means without fitting or inventing another mean.
  • fpca= accepts marginal and pooled multivariate fits. Node count, subject count, and available IDs are checked. means= accepts a vector per node. Conflicting mean sources and unused mean-bandwidth overrides throw.
  • The helper takes one shared scalar or scalar-candidate CurveCV for covariance smoothing. Direct cross fits support anisotropic fixed widths. No unrequested mapping from arbitrary pairwise widths to diagonal widths is inferred. Mean bandwidths and grids can be supplied per node.
  • The helper always smooths, including complete-grid inputs, to return the specified existing diagonal estimators. The separate dense estimator is the explicit unsmoothed route.
  • Equal-time exclusions use exact original times before snapping. Subject weights retain denominator N1_i*N2_i after exclusions. A subject with no surviving pairs throws. Single observations per node are otherwise allowed in a cross fit, provided the pooled pair cloud identifies the local fits.
  • Binned CV uses snapped pair coordinates, matching the existing covariance smoother. Within-cell scatter preserves the full raw-product squared loss. Means are evaluated before snapping and remain fixed across CV folds.
  • Off-diagonal fits store independent copies of the means. Transposed blocks copy grids, weights, means, selection records, and surfaces, and reverse the axis-specific settings. Mutating one block does not mutate its reverse.

The local roadmap records these API additions. The externally linked plan was inaccessible during development and still needs these additions, including the existing covariance estimator's grid-mean input form.

Reproduction and checks

Reference generation uses R 4.5.1 and fdapace 0.6.0:

Rscript test/reference/fdapace_m4.R

The committed generator writes fixed two-node sparse inputs and both same-time variants of GetCrCovYX's full 51 by 51 surface. Bandwidths are (.55,.8), the kernel is Epanechnikov, supplied means are linear, and weighting is one per observation pair. The script asserts that fdapace's exact-duplicate aggregation is exercised. CSV headers retain versions. CI reads these files and does not run R.

To rerun these tests against KernelSmoothing's GitHub master in a temporary environment without a Manifest:

testenv=$(mktemp -d)
julia +release --project="$testenv" -e 'using Pkg; Pkg.add(PackageSpec(url="https://github.com/mlakolar/KernelSmoothing.jl", rev="master")); Pkg.develop(PackageSpec(path=pwd())); Pkg.add(["Test", "DelimitedFiles", "StatsAPI"])'

Recovery interpretation

The seeded Gaussian recovery test uses 1,000 subjects, five times sampled from an eleven-point grid per subject, a shared standard Gaussian score, node functions 1+.5t and .7-.2t, and independent Gaussian measurement noise with standard deviation .4. The analytic cross-covariance is their outer product. Maximum absolute error must be below .2 with either same-time setting; changing that setting must change the surface by less than .08. These are finite-sample diagnostic tolerances, not a statistical guarantee.

The correlated-noise check isolates systematic bias using 125 sparse designs, each repeated for eight balanced sign patterns (1,000 subjects). Six orthogonal nonconstant Walsh columns represent one score and five time-specific errors, each with unit second moment and zero cross moments. Both nodes share errors with standard deviation two. This makes all off-time error products cancel exactly while retaining same-time noise covariance four. The mean diagonal bias with same-time pairs must exceed .5; excluding them must recover the analytic surface within .03 and reduce Frobenius error by at least a factor of three. This checks the exclusion rule and smoothing bias separately from high-noise sampling variation. It does not assert that every Gaussian sample of 1,000 subjects has such a small maximum error.
