Regression

The package fits Gaussian functional regression models by two routes. FPC regression has no smoothing parameter: β is expanded in leading FPCs. PenalizedFunctionalRegression, penalized FunctionOnScalarRegression and PenalizedFunctionOnFunctionRegression expand β in a spline basis and select their smoothing parameters by REML (default) or GCV through PenalizedLeastSquares. Concurrent regression records the bandwidths it uses on the fit.

All estimators follow the StatsAPI interface: fit, predict, coef, fitted, and, where the model defines them, residuals, vcov, stderror, nobs, dof and dof_residual. Each one stores every tuning choice on the fit and shows it with show.

Scalar-on-function regression

FPCRegression fits a Gaussian scalar response to one or more functional covariates and optional scalar covariates:

\[y_i = \alpha + z_i^\top\gamma + \sum_j\sum_{k=1}^{K_j} b_{jk}\xi_{ijk} + \epsilon_i, \qquad \beta_j(t)=\sum_{k=1}^{K_j}b_{jk}\phi_{jk}(t).\]

FPCA scores describe centered curves. Dense fits use the stored quadrature weights, including on nonuniform grids. Basis fits use exact basis inner products. Sparse fits use the existing PACE conditional expectation scores. The regression uses an intercept and ordinary least squares, with no regression smoothing parameter. The intercept is for centered functional covariates and uncentered scalar covariates. A deliberately uncentered basis FPCA retains its own score convention; its intercept must be interpreted in that convention.

Fit and inspect a model

The offline Tecator sample contains three spectra and their fat percentages. One component leaves one residual degree of freedom. This example illustrates the interface; use the full dataset for a substantive analysis.

using FunctionalDataAnalysis
import StatsAPI
tecator = load_dataset(:tecator; sample=true)
model = StatsAPI.fit(FPCRegression, tecator.data, tecator.covariates.Fat;
    ncomponents=1)
(StatsAPI.coef(model), model.sigma2, StatsAPI.r2(model))
([23.666666666666668, 5.102259160553307], 2.829908956338567, 0.9943905178405669)
beta = only(coefficient_functions(model))
values = evaluate(beta, tecator.data.grid)
pointwise = only(coefficient_bands(model))
coordinates = band_data(pointwise) # band_plot(pointwise) uses the existing ribbon recipe
predictions = predict(model, tecator.data; interval=:prediction)
(StatsAPI.fitted(model), predictions.lower, predictions.upper)
([21.139638843526885, 40.615810200313334, 9.244550956159792], [-3.659394743873751, 11.106329470006166, -19.015121285811677], [45.938672430927525, 70.12529093062051, 37.50422319813126])

Pass a tuple of functional datasets, or MultivariateFunctionalData, for multiple predictors. Domains and sampling designs may differ. Subjects must have the same row order; conflicting subject IDs throw. For example, fit(FPCRegression, (x1, x2), y; scalar_covariates=Z, ncomponents=(2, 1)) fits two and one components, respectively.

coef orders parameters as intercept, scalar coefficients, then the score coefficients of each functional covariate. vcov and stderror use that same order. coefficient_functions returns a tuple of BasisFunctionalData, even for one predictor. This preserves exact basis eigenfunctions when available. fitted, residuals, nobs, dof, dof_residual and r2 follow StatsAPI. Here dof counts regression coefficients, and sigma2 is RSS divided by dof_residual. Rank deficiency, nonfinite inputs, zero response variation and nonpositive residual degrees of freedom throw informative errors. Nullable response and scalar containers are accepted when every entry is finite and observed; actual missing values throw and no subjects are dropped. The solve uses Julia's pivoted QR. Iterative proximal or coordinate descent methods, including ProximalSolvers.jl and CoordinateDescent.jl, would add iteration and stopping choices to this unpenalized least-squares problem; no optimization solver or runtime dependency is added.

fpca_options=(; max_k=5) passes settings to FPCA. For different settings per predictor, pass a tuple of named tuples. All smoothing, noise and eigenanalysis choices remain in each marginal FPCA, and are shown with the regression fit. See FPCA for defaults and existing departures from R, including the estimated measurement-noise floor. Regression does not add a second smoother or conditional expectation solver.

A supplied fpca may be one fit or a tuple/vector with a fit or nothing per covariate. The model copies supplied fits. It uses stored scores only for observations equal to the fit's stored training data; different observations are projected with that fit. This also preserves fitted preprocessing and FACE completion for training observations. Tuning options for supplied fits throw. ncomponents may choose a fixed count or an existing FPCA selector per fresh fit; for supplied fits it may retain or truncate the available harmonics using a fixed count or FVE. It cannot recover discarded eigenfunctions.

Optional regression selection uses selection=AIC(), BIC() or :loocv. Use fpca_options=(; max_k=...) to limit fresh candidate bases. AIC and BIC minimize n*log(RSS/n) + c*dof, with c=2 or log(n). The additive Gaussian likelihood constant is omitted. LOOCV minimizes mean squared held-out response error and refits FPCA in every fold, so it costs n FPCA fits per covariate for each candidate count tuple; keep max_k small with several covariates. Supplied fits are rejected for LOOCV because the procedure that produced them is not recoverable in general. Selection searches all positive leading-component counts, jointly across predictors. It records candidate counts, criteria, failures and the winner. Nonestimable candidates receive infinite criterion with an explicit reason; if none is estimable, fitting throws. Exact ties choose the first lexicographic count. Candidate search can be expensive with many predictors.

These are leading-component models. fda.usc fregre.pc.cv instead normally performs stepwise component subset selection. It defaults to kmax=8 and criteria="SIC"; neither overrides fdapace's FVE default here. Its AIC/SIC values are the corresponding package criterion divided by n. Its CV source refits FPCA but additionally divides each held-out residual by n-ck, where ck=n-out$df.residual for the fold. The package deliberately uses ordinary LOOCV prediction MSE, without this extra scaling, to measure held-out prediction error directly. The reference script compares that documented quantity using real fregre.pc fold fits and also saves the scaled R quantity.

Prediction and uncertainty

Native prediction reuses each stored FPCA fit. PACE accepts grid and irregular observations within its domain. Dense FPCA requires its complete training grid. Basis FPCA requires its training basis. New basis curves can be evaluated exactly on a raw fit's grid. Other conversions require an explicit evaluator=PiecewiseLinear() or NoInterpolation(); every curve must cover the fitted grid. For a basis fit this explicitly requests numerical projection using its stored work-grid quadrature, which approximates exact basis integration. No interpolation or basis approximation is chosen implicitly.

coefficient_bands, fitted_bands and predict(...; interval=:confidence) use the conditional OLS covariance sigma2*(D'D)^(-1), computed through pivoted QR and triangular solves. A confidence interval describes the conditional mean response. interval=:prediction adds independent Gaussian response noise. Returned interval objects record their target, alpha, critical value and uncertainty convention. These are pointwise intervals, with no simultaneous coverage claim. They exclude uncertainty in estimated means, eigenfunctions, sparse latent scores, truncation and model selection, and omit discarded modes. In particular, sparse intervals condition on the PACE score estimates.

fdapace FLM itself returns no standard errors. Its separate FLMCI defaults to level=0.95 and R=999 subject-bootstrap refits of FPCA and regression, reporting R quantile (type 7) percentile intervals. coefficient_bands(model; method=:bootstrap, B=999, rng) performs the same refits with the stored FPCA options and component rules; see Bootstrap intervals. The conditional default follows fda.usc's linear-model covariance and Student-t prediction formula.

Function-on-function regression

Pass a univariate functional response to FPCRegression. As in fdapace 0.6.0 FLM, the response is reduced to its own FPCA scores η_ik. Each response score is regressed by OLS on the same design of covariate scores (and scalar covariates), giving a p × K_Y coefficient matrix B:

\[\beta_j(t,s) = \sum_{k,l} \phi_{jk}(t)\, B_{jk,l}\, \psi_l(s), \qquad \hat Y_i(s) = \mu_Y(s) + \sum_l (D B)_{il}\,\psi_l(s).\]

using FunctionalDataAnalysis
import StatsAPI
grid = collect(range(0.0, 1.0; length=21))
u = 2pi .* (1:30) ./ 30
x = GridFunctionalData(cos.(u) .* transpose(sinpi.(grid)) .+
    0.5 .* sin.(2u) .* transpose(sinpi.(2grid)), grid)
y = GridFunctionalData(1 .+ (0.8cos.(u) .- 0.3sin.(2u)) .* transpose(sqrt(2) .* sinpi.(grid)) .+
    0.3 .* sin.(5u) .* transpose(cospi.(2grid)), grid)
fof = StatsAPI.fit(FPCRegression, x, y)
(ncomponents(fof), size(StatsAPI.coef(fof)), StatsAPI.r2(fof))
([2], (3, 2), 0.9419354838709678)
surface = only(coefficient_functions(fof))   # (; grid, response_grid, values)
intervals = only(coefficient_bands(fof))     # pointwise conditional surfaces
curves = StatsAPI.predict(fof, x[1:3])       # GridFunctionalData on the response grid
r2_by_time = pointwise_r2(fof)
size(surface.values), size(curves.values)

The response FPCA is controlled like the covariates: response_fpca supplies a fit, response_fpca_options tunes a fresh one, and response_ncomponents fixes or truncates its count. Surfaces have the covariate grid t in rows and the response grid s in columns, the orientation of fdapace's betaList. The intercept function μ_Y(s) + B_{0·}ψ(s)' is reconstruct(fof.response_fpca, reshape(StatsAPI.coef(fof)[1, :], 1, :)).

pointwise_r2(fof) returns 1 - Σ_i r_i(s)² / Σ_i (Ỹ_i(s) - mean(s))² for the reconstructed responses Ỹ. fdapace reports only the scalar R2. Where every retained response eigenfunction vanishes (for example at the endpoints of sine eigenfunctions), the ratio is 0/0 and the value is NaN.

These intervals condition on both FPCAs. They exclude truncation and measurement error of the response, which are not part of its retained components.

Bootstrap intervals

coefficient_bands(model; method=:bootstrap, B=999, alpha=0.05, rng=nothing) follows fdapace 0.6.0 FLMCI for scalar and functional responses. Each replicate resamples subjects with replacement and refits every FPCA and the regression with the stored options and component rules. FVE selection may therefore choose a different number of components in each replicate. The refitted coefficient functions are evaluated on the requested grids, and R type-7 quantiles give pointwise percentile intervals. se is the bootstrap standard deviation and critical_value is nothing.

As in FLMCI's dense branch, a resample is redrawn until every functional variable keeps its original observed time range, so refitted work grids agree. After 1000 consecutive rejections the call throws. FLMCI's sparse branch instead samples from all but 2(p+1) curves, then appends curves forced to contain each boundary. The package uses plain subject resampling with the range check for every design. Bootstrap intervals require fresh FPCA fits and selection=:fpca. Supplied fits throw because their fitting procedure cannot be repeated. rng=nothing uses Random.default_rng(). The RNG is copied, so the caller's state is unchanged, and its initial state is stored as settings.rng_state. A replicate that fails to refit throws with its number; no draw is dropped. FLMCI passes optnsListY as the covariate options of its point estimate, an apparent slip; the package uses the fitted model itself.

Concurrent regression

ConcurrentRegression implements fdapace 0.6.0 FCReg. fdapace 0.6.0 no longer contains ConcurReg; FCReg is its successor with the same two-dimensional smoothing estimator. Dense and sparse designs use the same code, and covariates and the response may be observed at different times:

\[\beta(t) = C_{XX}(t,t)^{-1} C_{XY}(t,t), \qquad \beta_0(t) = \mu_Y(t) - \sum_j \beta_j(t)\mu_j(t).\]

using FunctionalDataAnalysis
import StatsAPI
grid = collect(range(0.0, 1.0; length=11))
u = 2pi .* (1:30) ./ 30
x = GridFunctionalData(cos.(u) .* transpose(1 .+ grid) .+
    0.5 .* sin.(2u) .* transpose(cospi.(grid)) .+ transpose(grid), grid)
y = GridFunctionalData(transpose(1 .+ 0.5grid) .+ x.values .* transpose(1.2 .- 0.8grid) .+
    0.1 .* sin.(7u) .* transpose(cospi.(3grid)), grid)
concurrent = StatsAPI.fit(ConcurrentRegression, x, y;
    mean_bandwidth=0.15, covariance_bandwidth=0.2)
StatsAPI.coef(concurrent)   # intercept row, then one row per covariate

Each functional variable is centered by a local linear mean evaluated at its own sorted unique observation times. Linear interpolation, with constant extrapolation as in approxfun(rule=2), gives the mean elsewhere. All within-subject products of centered values are smoothed by the existing bivariate local linear smoother (KernelSmoothing.jl) with unit weights and the covariance bandwidth on both axes. Only the diagonal (t,t) is evaluated. With measurement_error=true, a variable's own products drop equal-time pairs (FCReg's rmDiag), removing noise variance from C_XX and C_YY. Scalar covariates add varying coefficients. Their products with functional variables are smoothed by the univariate local linear smoother; their own covariances are sample covariances. pointwise_r2 returns FCReg's R2(t) = C_YX β / C_YY, clipped to [0,1].

Function-on-scalar regression

FunctionOnScalarRegression fits

\[Y_i(t) = \sum_{k=1}^{q} x_{ik}\,\beta_k(t) + \epsilon_i(t), \qquad \beta_k(t) = \phi(t)^\top b_k,\]

with x_i = [1, z_i]. Scalar covariates are a vector or matrix, or a Tables.jl table whose non-numeric columns are factors. Factor levels are sort(unique(column)) and enter through treatment contrasts against the first level, as in R's model.matrix; the design column names are stored in settings.design_columns. Grid (also with missing values), irregular and basis responses are accepted.

Penalized fit with REML (default)

Without lambda, every coefficient function is a penalized spline and the smoothing parameters are chosen by REML on the penalized least-squares solver. Grid and irregular responses are fitted at their observed points; basis responses in the L2 norm.

The model is the scalar-term model of refund's pffr: working-independent Gaussian errors, a penalized spline for each coefficient function and one smoothing parameter each. pffr is the default reference because it is the refund fit that selects smoothing parameters by REML (fosr does not; see the audit below). The coefficient basis follows fosr instead of pffr: 15 cubic B-splines with equally spaced knots on the response domain and the integrated squared second derivative penalty. This is the package's B-spline basis and roughness penalty, the same space and penalty as mgcv's bs basis with m=c(3,2). basis=:pffr uses pffr's own defaults instead: mgcv P-spline bases (PSplineBasis) with 20 cubic functions for the intercept and 5 for every other coefficient, first-order difference penalties, and knots on the range of the observation times widened by 0.1%, as mgcv places them (for a grid response, the range of the whole grid, which is the same unless an end point is missing for every curve). Any basis, or one basis per coefficient (sharing one domain), can be supplied with basis; for a grid response its domain must contain the whole grid, since fitted curves and default bands are returned there, and penalty_order changes the penalty; for a PSplineBasis it is the order of the coefficient differences. Every column of x_i gets its own coefficient function: a factor contributes one varying coefficient per non-reference level.

The smoothing parameters, their statuses, the criterion value, the error variance sigma2 (mgcv's scale estimate, the residual sum of squares over N - edf), the effective degrees of freedom edf of each coefficient function, the solver settings and all choices above are stored on the fit and shown by show. dof is the total EDF and dof_residual the number of observations minus that EDF. fitted returns curves on the full response grid (grid), at the observation times (irregular) or in the response basis; residuals keeps the observed points of the response, so missing grid values stay missing. predict(fos, z) returns BasisFunctionalData in the coefficient basis when all coefficients share one basis, and curves on a grid (GridFunctionalData) when they do not, as with basis=:pffr.

Residual correlation

Errors of one curve are usually correlated. The point estimate assumes working independence, as pffr and fosr's OLS fit do; covariance chooses how the uncertainty accounts for the correlation:

Here A = XᵀX + S_λ and N is the number of curves. :cluster needs no common grid and is robust to any within-curve correlation.

The default departs from the posterior covariance Vp (mgcv's default, and the covariance originally specified for these bands). refund 0.1.40 made the cluster sandwich pffr's default because Vp treats the points of one curve as independent observations: with correlated residual curves, as functional data nearly always have, Vp understates the uncertainty of the coefficient functions and the bands undercover. covariance=:bayesian gives Vp. :pooled assumes one residual covariance for all curves and needs a complete common grid or a basis response. The field residual_covariance holds Σ̂, the covariance of the residual curves divided by n (fosr's (n-1)/n times cov), on the response grid, or of the residual coefficients for basis responses. For irregular and incomplete grids it is a 0×0 matrix: estimating it requires smoothing, for example fit(FPCA, residuals(fos)).

Refitting with the residual structure, as fosr's method="GLS" (a whitening refit by the estimated residual covariance) and method="mix" (residual functional principal components as random effects) do, is not offered. refund 0.1.40 removed pffr's GLS variant (pffr_gls) because it gave poorly calibrated inference and recommends the cluster sandwich instead; fosr's GLS route also inherits the helper defects listed in the audit. Intervals condition on the selected smoothing parameters. interval=:prediction adds the error variance sigma2.

Fixed smoothing parameters

Supplying lambda keeps it fixed. A basis response with supplied lambda follows fda 6.3.0 fRegress with scalar covariates and a fixed fdPar penalty (method=:fRegress, chosen automatically). Each coefficient function uses the response basis, and the coefficients solve

\[\bigl(X^\top X \otimes G + \operatorname{blockdiag}(\lambda_k R_k)\bigr)\, b = \operatorname{vec}(G\, Y^\top X),\]

with exact Gram matrix G and penalty matrices R_k from the package's bases. These are the normal equations of the penalized basis-response fit, so the coefficients agree with method=:penalized at the same λ; the covariance follows fRegress.stderr instead.

using FunctionalDataAnalysis
import StatsAPI
basis = BSplineBasis(4, (0.0, 1.0), 7)
u = 2pi .* (1:30) ./ 30
z = cos.(u)
coefs = 1 .+ z .* transpose(sin.(1:7) ./ 2) .+ 0.1 .* sin.(3u) .* transpose(cos.(1:7))
fixed = StatsAPI.fit(FunctionOnScalarRegression, z, BasisFunctionalData(coefs, basis); lambda=1e-4)
intercept, slope = coefficient_functions(fixed)
bands = coefficient_bands(fixed)        # pointwise intervals, intercept first
StatsAPI.predict(fixed, [0.5, -0.5])    # BasisFunctionalData

The package follows fdapace's FVE default because it adapts the count to the functional predictor. A fixed ncomponents=3 provides the corresponding three-leading-component model. With a functional response, FLM fits the response FPCA with optnsListY and calls GetBR2New, which runs one lm per response score. There are inherited discretization differences. fdapace uses rectangular covariance eigenanalysis and then trapezoidal harmonic normalization; fda.usc uses Euclidean SVD with uniform-grid normalization. Its inner-product helper is named int.simpson2, but the global int.method default is "TRAPZ". The package consistently uses stored quadrature weights. Dense and sparse golden fixtures use sine subspaces vanishing at the endpoints, where these eigensteps agree. Sparse fixtures supply the same mean, covariance and noise to isolate the regression and CE route from existing smoother differences. Its coefficient solve is qr.solve at each output point. Its summaryConReg helper is empty; no intervals or bandwidth defaults exist.

fRegress.fd forms its normal equations with inprod, which integrates by Romberg extrapolation with relative tolerance 1e-4 unless both arguments are B-spline objects passed with integer derivative orders. With interior knots this leaves relative errors near 1e-5 in the fitted coefficients. The package uses exact Gram matrices. bsplinepen computes B-spline penalties exactly for bases with interior knots, but for a B-spline basis without interior knots it substitutes a monomial basis and returns that basis's penalty matrix, which does not apply to B-spline coefficients. Penalized scalar-on-function regression

PenalizedFunctionalRegression fits the same Gaussian model with each coefficient function expanded in a spline basis and penalized for roughness, as refund's pfr(y ~ z + lf(X1) + lf(X2), method="REML") (Goldsmith, Bobb, Crainiceanu, Caffo and Reich 2011):

\[y_i = \alpha + z_i^\top\gamma + \sum_j \sum_t L_{jt} X_{ij}(t)\, B_j(t)^\top b_j + \epsilon_i, \qquad \text{penalty } \sum_j \lambda_j b_j^\top S_j b_j .\]

L_jt are integration weights on the covariate grid, B_j a basis and S_j its penalty. Each functional covariate has its own smoothing parameter, chosen by REML through PenalizedLeastSquares (the solver of the Penalized fitting page). The intercept and scalar covariates are unpenalized.

Integration weights. refund's "simpson" weights are (t_J - t_1)/J/3 * [1, 4, 2, 4, …, 2, 1]. The package therefore integrates with the grid's stored trapezoidal weights, the same weights it uses for every other inner product and identical to refund's integration="trapezoidal". integration=:refund_simpson and :riemann reproduce refund's two other formulas exactly, and a weight vector may be supplied.

Sparse, noisy and basis covariates

Grid covariates with missing values and irregular covariates need a presmoother, as in refund, where lf(presmooth=) reconstructs curves before fitting. :bspline fits cubic B-splines per curve by least squares, with interior knots at quantiles of the grid as R's splines::bs(df=nbasis, intercept=TRUE). :interpolate interpolates observed values linearly and holds them constant beyond the first and last observation (R approx(rule=2)). :fpca fits the package's FPCA (PACE for sparse data, with presmooth_options passed to fit(FPCA, ...)) and uses its reconstruction mean + scores × eigenfunctions on the FPCA work grid or a supplied grid; refund uses its own fpca.sc, fpca.face or fpca.ssvd here, so this option is not numerically comparable to refund. New subjects are presmoothed with the stored presmoother: projected onto the training FPCA, or smoothed per curve. Basis covariates are evaluated exactly on a required grid. Only the presmoothed curves enter the regression: as in refund, presmoothing and FPCA uncertainty are not propagated to the covariances or bands.

Uncertainty

vcov(fit; type=:bayesian) is the posterior covariance (XᵀX + S_λ)⁻¹σ² (mgcv Vp), :frequentist is mgcv Ve, and :corrected is mgcv's Vc. Vc adds a first-order term J V_ρ Jᵀ, with J = ∂b̂/∂log λ and V_ρ the inverse Hessian of the REML criterion over (log λ, log σ²), and the second-order Cholesky-derivative correction of Wood, Pya and Säfken (2016), both as in mgcv 1.9-3 gam.fit3.post.proc. It exists only after REML selection, and settings.corrected_covariance says whether it was computed (:mgcv_Vc). When a smoothing parameter is effectively infinite, XᵀX + S_λ is numerically singular and the derivatives with respect to log λ carry no information, so Vc is not formed (:unavailable_infinite_lambda); the same holds if the Cholesky factorization fails (:unavailable_not_positive_definite). Bands and intervals then default to Vp. mgcv still reports a Vc in these cases. Bands are pointwise normal intervals. refund offers no simultaneous bands for pfr, and none are returned. dof is the total effective degrees of freedom (intercept and scalar coefficients included), edf_terms the effective degrees of freedom of each functional term, and sigma2 mgcv's RSS/(n - dof).

Choosing a regression method

Both fits return a tuple of coefficient functions, coef, vcov, fitted, residuals, predict and coefficient_bands, so downstream code can use either. FPC regression truncates to leading components of the covariate and conditions on the FPCA; it suits strongly smooth covariates whose leading modes carry the signal, and sparse designs through PACE scores. Penalized regression lets the response choose the smoothness of β through REML, does not tie β to the leading covariate modes, accounts for smoothing parameter uncertainty in its bands, and is the better choice when β has features in directions of small covariate variance or when several dense covariates need separate smoothness.

The regression study compares three fits with their default settings:

  • fit(FPCRegression, x, y);
  • the same fit with selection=BIC();
  • fit(PenalizedFunctionalRegression, x, y), with presmooth=:fpca for sparse curves.

Covariates are simulated with simulate_kl from nine Fourier components with eigenvalues 1/k². They are observed with noise either on a dense grid or at 2–10 random times per curve. The coefficient β(t) takes three forms:

  • aligned with the two leading eigenfunctions;
  • equal to the trailing eigenfunction, which FVE(0.99) drops in population;
  • a smooth bump unrelated to the eigenfunctions (Reiss and Ogden 2007).

The other factors are n ∈ {100, 500} and a population R² of 0.8 or 0.5, with 200 replicates per cell. The study records:

refund and mgcv source audit

The audited sources are refund 0.1-40 (pfr.R, lf.R, create.prep.func.R, coefficients.pfr.R, predict.pfr.R) and mgcv 1.9-3 (smooth.construct.tp.smooth.spec, tprs.c, smoothCon, gam.fit3.post.proc, Vb.corr, vcorr, dchol). Findings:

  • pfr rewrites each lf(X) as s(X.tmat, by=L.X) with matrix arguments, so the term is Σₜ L_t X(t) f(t) (mgcv's summation convention) and calls gam(method="REML"). A centering constraint is added only when the row sums of L*X are constant; the package throws instead, because the term is then confounded with the intercept.
  • mgcv computes the penalty scale from the unweighted basis at the grid, before the by weights are applied, and rescales thin plate columns to unit root mean square.
  • The thin plate basis uses η(r)=|r|³/12, the k eigenvalues of largest magnitude by Lanczos iteration (tolerance eps^0.7) and a Householder absorption of Tᵀδ = 0. On grids symmetric about their mean (every uniform grid) the absorption depends on entries that are zero in exact arithmetic, so mgcv's columns there depend on rounding in its eigenvectors. The function space, the penalty, β, fitted values, Vp and Ve do not; mgcv's Vc does, through its Cholesky-based second-order term.
  • lf() integration weights are as described above; predict.pfr reuses the training weights and presmoother for new curves on the training grid.
  • coef.pfr uses Vc by default and returns standard errors only; fpca.ssvd presmoothing cannot predict new curves (refund warns).

FunctionalDataAnalysis.ThinPlateRegressionBasis — Type
ThinPlateRegressionBasis(points, k=10)

The rank-k thin plate regression spline basis of mgcv 1.9-3 s(x, bs="tp") in one dimension, with penalty order m = 2 (∫f''(t)²dt). It is refund's default lf() basis, where k=10 is mgcv's default dimension.

The finite points (usually a covariate grid; ties are merged) are the knots of the full spline. Their mean is subtracted for stability (mgcv shift). With η(r) = |r|³/12 and E[i,j] = η(xᵢ-xⱼ) over the u distinct points, the basis keeps the eigenvectors U of the k eigenvalues of E of largest magnitude (ordered by decreasing value), imposes Tᵀδ = 0 for the null-space polynomials T = [1, x] by mgcv's Householder factorization, and appends T. Functions are f(t) = Σⱼ η(t-xⱼ)δⱼ + α₀ + α₁t with [δ; α] = UZ * γ. As in mgcv, every column is scaled to unit root mean square over the supplied points. When u == k no eigen truncation is applied. mgcv uses a Lanczos iteration with relative tolerance eps^0.7; this basis uses LAPACK's symmetric eigensolver, so it agrees with mgcv up to column signs and the Lanczos tolerance. On points symmetric about their mean, some Householder signs in mgcv's construction are decided by rounding noise; this basis uses the exact-arithmetic choice, so its columns can then differ from mgcv's by a rotation of the same function space and penalty.

The domain is the range of points. penalty(b, 2) integrates f''² exactly over the domain (the functions are natural cubic splines, so this equals mgcv's penalty γᵀSγ, available unscaled as b.penalty). basis_matrix supports derivatives of any order (zero beyond the third).

Penalized function-on-function regression

PenalizedFunctionOnFunctionRegression fits functional responses on functional and scalar covariates with penalized splines, as refund's pffr(Y ~ z + ff(X1) + ff(X2)) (Ivanescu, Staicu, Scheipl and Greven 2015; Scheipl, Staicu and Greven 2015):

\[Y_i(s) = \beta_0(s) + \sum_k z_{ik}\beta_k(s) + \sum_j \sum_t L_{jt} X_{ij}(t)\,\beta_j(t,s) + \epsilon_i(s), \qquad \beta_j(t,s) = \sum_{a,b} \theta_{jab} B_a(t) B_b(s).\]

Each surface β_j is a tensor product of cubic P-splines with two smoothing parameters, one per direction. The intercept and scalar-term functions are those of FunctionOnScalarRegression with basis=:pffr. Every smoothing parameter is chosen by REML on the stacked observations (i, s) through PenalizedLeastSquares, and the default covariance is pffr's cluster sandwich, which allows for correlated errors within a curve.

using FunctionalDataAnalysis, LinearAlgebra, Random
import StatsAPI
rng = Xoshiro(11)
tgrid = collect(range(0, 1; length=30))
sgrid = collect(range(0, 1; length=25))
modes = hcat(sinpi.(tgrid), cospi.(tgrid), sinpi.(2 .* tgrid), cospi.(2 .* tgrid))
X = randn(rng, 60, 4) * transpose(modes) .+ 0.05 .* randn(rng, 60, 30)
z = randn(rng, 60)
surface_true(t, s) = cospi(t - s) * (1 + s)
Y = transpose(1 .+ sinpi.(2 .* sgrid)) .+ z .* transpose(1 .- 2 .* sgrid .^ 2) .+
    X * (quadrature_weights(tgrid) .* surface_true.(tgrid, transpose(sgrid))) .+
    0.1 .* randn(rng, 60, 25)
x = GridFunctionalData(X, tgrid)
y = GridFunctionalData(Y, sgrid)
pffr = StatsAPI.fit(PenalizedFunctionOnFunctionRegression, x, y; scalar_covariates=z)
(pffr.lambda, pffr.edf, pffr.settings.sigma2)
([0.12527551413414573, 0.0038916408117944954, 1.0335999738883117, 0.8879997372180443], [18.205503399431095, 4.972947652440133, 18.794648793949616], 0.01013328556026985)

lambda lists the intercept, the scalar coefficient, then the t and s directions of the surface; edf the effective degrees of freedom of the intercept, the scalar coefficient and the surface.

Responses on grids and at irregular times

Basis responses throw (pffr takes no fd objects); convert them with to_grid. The stacked design is dense, with one row per observed value and 20 + 5q + Σ_j k_t k_s columns for q scalar covariates. refund switches from gam to bam above 10⁵ observations; the package always solves the same penalized least squares problem.

Uncertainty

vcov(fit) is the covariance chosen by covariance. The cluster sandwich n/(n-1) A⁻¹ (Σ_i D_iᵀr_i r_iᵀD_i) A⁻¹ + Vp - Ve (with n curves, A = DᵀD + S_λ, and the rows D_i and residuals r_i of curve i) accounts for correlation of the errors within a curve; Vp treats the points of one curve as independent. Surface bands use the variance (B(t) ⊗ B(s))ᵀ V (B(t) ⊗ B(s)) of each point. Prediction intervals add the error variance settings.sigma2 (mgcv's sig2). Bands and intervals are pointwise; smoothing parameters and presmoothed covariates are treated as fixed. dof is the total effective degrees of freedom and dof_residual the number of observed values minus dof.

refund and mgcv source audit for pffr

The audited sources are refund 0.1.40 (pffr, pffr_prepare, pffr_process_ff_terms, pffr_configure_algorithm, ff, compute_integration_weights, trace_lv, the arguments of coef.pffr) and mgcv 1.9-3 (smoothCon, smooth.construct.tensor.smooth.spec, smooth.construct.ps.smooth.spec). Findings:

  • pffr stacks the response in long format (one row per observed value) and rewrites ff(X) as te(X.smat, X.tmat, by=L.X) with matrix arguments: X.smat repeats the covariate grid, X.tmat the response index of the row and L.X the weighted curve, so mgcv's summation convention gives Σ_t L_t X_i(t) f(t, s). It then calls gam(method="REML").
  • ff() defaults to integration="simpson" with refund's formula (t_J - t_1)/J/3 · [1, 4, 2, …, 1], switching to "trapezoidal" on grids that are not equidistant. limits (historical models) switch to Riemann sums; they are not supported here.
  • mgcv te reparameterizes each one-dimensional margin to function values at equally spaced points of the margin's data range (skipped with a warning when the evaluation matrix is near singular, which the package mirrors) and divides each marginal penalty by its largest eigenvalue before forming S_t ⊗ I and I ⊗ S_s. smoothCon then scales each penalty by ‖S‖₁/‖X‖∞² from the unweighted basis, before the by weights.
  • With a numeric matrix by variable, mgcv adds no centering constraint unless the row sums of L.X (the integrals ∫X_i) are constant; the package throws in that case, as the surface is then confounded with the intercept.
  • ff(check.ident=TRUE) warns when the covariate's effective rank (99.5% of its squared singular values) is at most 4 or below k_t, and replaces the term by a constrained ti() smooth when the null space of X overlaps the integration-weighted null space of the t penalty (overlap above 0.95) and the term's design has log10 condition number above 6. The package stores the three diagnostics on the term and throws where refund would constrain.
  • The functional intercept is a parametric constant plus a centered smooth; the package's uncentered P-spline spans the same space with the same penalty, so fits agree, but the REML score differs by a constant that does not depend on λ. The tensor penalties are applied in the original B-spline coordinates, S_t ⊗ G_s and G_t ⊗ S_s with G = B(u)ᵀB(u) at the reparameterization points u, which adds another λ-free constant.

Validation

Recreate the fixtures with Rscript test/reference/regression_m7f.R (R 4.5.1, refund 0.1.40, mgcv 1.9-3). test/regression_pffr.jl compares, at relative error below 1e-8 and at refund's selected smoothing parameters: pffr(Y ~ ff(X)) with trapezoidal weights (the package default), pffr(Y ~ z + ff(X)) with refund's default Simpson weights (integration=:refund_simpson), and the first model with an irregular response (ydata). The quantities are the surface on a 9 × 11 grid, its standard errors under Vp, Ve and the cluster sandwich, the intercept and scalar coefficient functions and their standard errors, per-term and total EDF, σ², fitted values and predictions for new curves. Because the REML scores differ by a constant, the change in the score between refund's smoothing parameters and twice them is compared instead, and the package's own optimum is checked to be no worse under its criterion. The irregular fit is also checked against the same points on a grid with missing values. No R installation is needed to use the package or run its tests.

Penalized function-on-function regression

Yᵢ(s) = β₀(s) + Σₖ zᵢₖ βₖ(s) + Σⱼ ∫ Xᵢⱼ(t) βⱼ(t, s) dt + εᵢ(s),

the model of refund 0.1.40 pffr(Y ~ z + ff(X1) + ff(X2)) with method="REML". x is one univariate functional dataset, a tuple/vector of them, or MultivariateFunctionalData; y is a GridFunctionalData (missing values allowed) or IrregularFunctionalData response, fitted at its observed points with unit weights as pffr does (an irregular response is pffr's ydata). Basis responses throw; convert them with to_grid.

Each surface βⱼ(t, s) is a tensor product of cubic P-splines in t (the covariate grid) and s (the response times) with one smoothing parameter per direction, ff()'s default te(bs="ps", m=list(c(2,1), c(2,1)), k=c(5,5)). As mgcv 1.9-3 te does, each marginal penalty (first differences of the coefficients) is reparameterized to k function values at equally spaced points of the margin's range and normalized to unit largest eigenvalue, so the two penalties are Sₜ ⊗ Gₛ and Gₜ ⊗ Sₛ with G = B(u)ᵀB(u) at those points u. The integral is the weighted sum Σₜ Lₜ Xᵢⱼ(t) βⱼ(t, s) over the covariate grid. The intercept and scalar-term functions are as in FunctionOnScalarRegression with basis=:pffr. Every smoothing parameter is chosen by REML (criterion=:REML, the default) or GCV (criterion=:GCV) on the stacked model with PenalizedLeastSquares.

Options and the source of each default:

  • scalar_covariates: nothing, a finite real vector or matrix (without an intercept column), or a Tables.jl table whose non-numeric columns are treatment-coded factors, as in FunctionOnScalarRegression. The functional intercept is always fitted (pffr's default formula).
  • k=(5, 5): marginal basis dimensions (kₜ, kₛ) of every surface (ff()'s splinepars); one integer sets both, and a vector gives one entry per functional covariate. The P-splines are cubic with first-order difference penalties (m=c(2,1)), with mgcv's knots on the covariate grid range and on the range of the observation times (for a grid response, the whole grid, as in FunctionOnScalarRegression).
  • integration=:quadrature: the covariate grid's trapezoidal weights, equal to ff(integration="trapezoidal"). This departs from ff()'s default "simpson" for the reason given for PenalizedFunctionalRegression: refund's Simpson weights divide by the number of grid points instead of the number of intervals. :refund_simpson and :riemann reproduce refund's formulas exactly; a vector supplies weights.
  • presmooth, presmooth_options, grid: how each covariate becomes values on its grid, exactly as in PenalizedFunctionalRegression (complete grid data are used as observed; ff() itself takes only a complete matrix).
  • basis=:pffr, penalty_order=nothing: the intercept and scalar-term bases and penalties, as in FunctionOnScalarRegression (pffr's bs.int and bs.yindex by default).
  • lambda=nothing selects every smoothing parameter; a vector fixes them, one per penalty in the order: intercept, each scalar coefficient, then t and s for each functional term.
  • covariance=:cluster (pffr's default sandwich="cluster", the sandwich of FunctionOnScalarRegression clustering residuals by curve), :bayesian (Vp, sandwich="none") or :frequentist (Ve).

ff() checks identifiability (check.ident=TRUE). The effective rank of each covariate (components explaining 99.5% of Σᵢ Xᵢ(t)²), the log10 condition number of the term's design and the overlap of the null spaces of X and of the t penalty are stored on the term. Where refund would replace the term by a constrained ti() smooth (overlap above 0.95 and log10 condition above 6), the fit throws instead; the constrained term is not implemented. A functional term whose integrals Σₜ LₜXᵢ(t) are equal for every curve throws (mgcv would add a centering constraint). ff()'s limits (historical models) are not supported.

coef orders coefficients as the intercept and scalar-term basis coefficients, then each surface's kₜkₛ coefficients with the t index varying slowest. edf holds the effective degrees of freedom of each coefficient function, then each surface; lambda one value per penalty. dof is the total effective degrees of freedom and dof_residual the number of observations minus dof. Intervals use the normal distribution. All choices are stored in settings and the functional terms in terms.

For a functional response, y is reduced to its own leading FPCA scores eta_ik and each response score is regressed on the same design, as fdapace 0.6.0 FLM (GetBR2New) does. Then beta_j(t,s) = phi_j(t)' B_j psi(s)', with covariate eigenfunctions phi_j and response eigenfunctions psi. coef returns the p × K_Y matrix B (rows in the scalar-response order, one column per response component), vcov the covariance of vec(B), SigmaE ⊗ inv(D'D), where SigmaE is the residual score cross-product divided by dof_residual = nobs - p. stderror has the shape of coef; dof counts all p*K_Y coefficients. sigma2 is tr(SigmaE), the integrated residual variance within the retained response components, and r2 is fdapace's score-scale R², 1 - sum(RSS_k)/sum(TSS_k). selection=AIC() or BIC() minimizes the Gaussian regression criterion over all positive leading-component counts, conditional on the fitted FPC bases. selection=:loocv minimizes held-out squared response error, refitting FPCA in every fold, as fda.usc 2.2.0 fregre.pc.cv does. It accounts for correlation of the errors within a curve. This departs from the posterior covariance Vp originally specified for the bands: Vp treats the points of one curve as independent and understates the uncertainty when residual curves are correlated, which is why refund 0.1.40 made the sandwich pffr's default.
  • :bayesian: the posterior covariance Vp = A⁻¹σ² under independent errors (pffr's sandwich="none"); :frequentist: Ve = A⁻¹XᵀXA⁻¹σ².
  • :pooled: fosr's residual-covariance sandwich A⁻¹ (Σ_i X_iᵀ Σ̂ X_i) A⁻¹ with Σ̂ the covariance of the residual curves divided by n, for complete grids and basis responses.

The refund comparisons in the test suite use :bayesian, :frequentist and :cluster for pffr with the package's B-spline basis, :bayesian and :cluster for pffr with basis=:pffr, and :pooled for fosr.

residual_covariance (the field) stores Σ̂ on the response grid for complete grids, the covariance of the residual basis coefficients (divided by n) for basis responses, and a 0×0 matrix for irregular or incomplete grids, where it is not estimated. Intervals use the normal distribution.

Fixed-lambda fit (lambda supplied)

method=nothing (the default) fits a BasisFunctionalData response with a supplied lambda (one nonnegative number or one per coefficient) by method=:fRegress, and everything else by method=:penalized, which with a supplied lambda evaluates the penalized fit at that fixed lambda. method=:fRegress follows fda 6.3.0 fRegress (its fRegress.fd method) with scalar covariates and a fixed fdPar lambda: the coefficients b = vec([b_1 ... b_q]) solve (X'X ⊗ G + blockdiag(lambda_k R_k)) b = vec(G Y' X). Standard errors follow fRegress.stderr: Var(b) = C^(-1) (X'X ⊗ G Σ_c G) C^(-1), with Σ_c the covariance of one response's basis coefficients. residual_covariance=:residual (the default) estimates Σ_c = E'E/(n-q) from the coefficient residuals with unpenalized residual degrees of freedom; a symmetric positive semidefinite nbasis × nbasis matrix supplies it instead. Intervals use Student t with n-q degrees of freedom for the estimate and the normal distribution for a supplied matrix. fRegress.stderr integrates with a Riemann sum on 501 points that gives full weight to both endpoints; the package uses exact inner products. criterion, shared_lambda, basis and covariance do not apply.

Grid and irregular responses with a supplied lambda use the penalized fit at that fixed lambda (one value with shared_lambda=true).

All choices are stored in settings and shown; bases holds the coefficient basis of each coefficient function. edf holds the effective degrees of freedom of each coefficient function (block traces of the influence matrix), lambda one value per coefficient.

Pointwise intervals for each coefficient function. method=:conditional (default) gives Student-t intervals conditional on the fitted FPCA and selected score design, as in fda.usc 2.2.0 fregre.pc's ordinary linear model. As in FLMCI's dense branch, a resample is redrawn until every functional variable has the original observed time range, so refitted work grids agree; 1000 consecutive rejections throw. Refitted coefficients are evaluated on the requested grids. se is the bootstrap standard deviation and critical_value is nothing. predict(f::FPCRegression, x; scalar_covariates=nothing, evaluator=nothing,

Predict new responses using stored FPCA fits and component counts. interval=:none returns a vector (scalar response) or GridFunctionalData of predicted curves mean_Y + D*B*psi' (functional response) on the response FPCA work grid or a supplied grid. :confidence and :prediction return pointwise conditional Student-t intervals with estimate, se, lower, upper, alpha, critical_value, and settings (functional responses add grid; arrays are subject × grid). Native FPCA representations use its existing prediction contract: PACE accepts both raw types, dense FPCA uses its complete training grid, and basis FPCA uses its training basis.
