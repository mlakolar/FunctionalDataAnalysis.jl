Multivariate FPCA (MFPCA)

Use project_scores(model, data) for joint score matrices or predict_scores(model, data) for ScorePrediction(scores, nothing). Joint conditional score covariance is unavailable; nothing does not mean zero uncertainty. Legacy StatsAPI.predict retains its matrix result and warns. See the prediction contract.

StatsAPI.fit(MFPCA, data; ncomponents=M) estimates joint principal components by the two-step construction of Happ and Greven (2018), Proposition 5. Nodes may have different domains, grids, observation designs, and univariate component counts. Each node is a univariate functional data object; higher dimensional domains supported by R MFPCA are outside this package's current API.

import StatsAPI
using FunctionalDataAnalysis

# data is a MultivariateFunctionalData object with two nodes
model = StatsAPI.fit(MFPCA, data; ncomponents=3,
    univariate=(; ncomponents=[2, 3]), weights=[1.0, 0.5])
joint_scores = scores(model)             # subjects × 3
node_functions = eigenfunctions(model)  # two FPCBasis objects, each with 3 columns
new_scores = StatsAPI.predict(model, newdata)
fitted_curves = reconstruct(model)

The univariate first step calls the existing marginal FPCA implementation. Keywords in univariate follow its shared/per-node convention. For example, univariate=(; method=[:dense, :pace], grid=[nothing, workgrid], noise_variance=[nothing, 0.05]) requests dense FPCA for the first node and PACE for the second. Its means, preprocessing, covariance smoothing, rank choices, and conditional score solver are reused and retained in model.univariate; component(model, j) returns the original univariate fit.

Construction and weights

Let $\Xi_j$ contain the $M_j$ selected univariate scores and let $\Phi_j$ denote their eigenfunctions, orthonormal under the node's stored quadrature. For positive node weights $w_j$, form

\[A = [\sqrt{w_1}\Xi_1\ \cdots\ \sqrt{w_p}\Xi_p],\qquad A_c = A-\mathbf{1}\bar A,\qquad Z_w = \frac{A_c^\top A_c}{n-1},\qquad Z_w c_m = \nu_m c_m.\]

The unit eigenvectors are ordered by decreasing eigenvalue. To match R MFPCA 1.3-11's exact route, normalization uses the uncentered matrix $Q=A/\sqrt{n-1}$. Define $h_m=\|Qc_m\|^{-1}$ and $b_m=Q^\top Qc_m\,h_m/\sqrt{\nu_m}$. The functions and scores are

\[\psi_m^{(j)} = w_j^{-1/2}\Phi_j b_m^{(j)},\qquad \rho_m = Ac_m\sqrt{\nu_m}h_m.\]

When the univariate scores have sample mean zero, $b_m=c_m$ and $\sqrt{\nu_m}h_m=1$. These formulas then reduce to Proposition 5:

\[\psi_m^{(j)} = w_j^{-1/2}\Phi_j c_m^{(j)},\qquad \rho_{im} = \sum_j \sqrt{w_j}\,\Xi_j[i,:]c_m^{(j)}.\]

In this mean-zero case, the weighted sum of node quadrature inner products is the identity: $\sum_j w_j \langle\psi_m^{(j)},\psi_\ell^{(j)}\rangle_j=\delta_{m\ell}$. Individual node components need not be orthonormal or even nonzero. Signs make the largest absolute entry of $c_m$ positive; the first entry breaks ties. Repeated eigenvalues define an eigenspace and can rotate within it.

The default weights are all one, following R. The paper also discusses $w_j=1/\int_{\mathcal T_j}\operatorname{Var}(X^{(j)}(t))\,dt$ to balance nodes of different scales. Supply such weights explicitly. Multiplying all weights by $a>0$ multiplies eigenvalues by $a$, scores by $\sqrt a$, and functions by $1/\sqrt a$; fitted curves are unchanged. Changing a node's units by $b$ is canceled by dividing its weight by $b^2$.

PACE conditional scores need not have sample mean zero. The covariance eigenproblem centers these scores, matching R's cov(allScores). Its eigenvalues describe the estimated scores' sample covariance, not the univariate latent PACE covariance spectrum. R's normalization and final score projection still use uncentered scores. Consequently, returned scores can have nonzero means, and the returned functions need not be orthonormal when these means are nonzero. This reproduces R's exact route rather than imposing another normalization. The normalization factors and score scales are stored in model.settings and shown with the fit.

Prediction calls univariate predict per node and applies the same weights and coefficients, followed by the stored R score scales. It does not subtract training or new-data score means. It returns a matrix, including when some nodes use PACE. FACE margins are available with univariate=(; method=:face, face=(; lambda=2.5)); omitting lambda uses the audited FACE GCV default. Their conditional score matrices pass through the same multivariate eigenproblem and prediction interface. Nodewise conditional covariances remain available from the marginal fit; joint conditional uncertainty would require cross-node assumptions and is not estimated here. Reconstruction adds each node's training mean to its multivariate expansion. It accepts a shared grid or one grid per node and keeps training IDs only when using the stored training score object.

Comparison with MFPCA

The source audit uses CRAN MFPCA 1.3-11 (published 2025-08-27), available as a versioned source archive. Its SHA-256 is aef336bd23edd8e9df2741f70d358066410b3217882054771d2cd002f2e65125. The audited files are R/MFPCA_calculation.R (MFPCA, calcMFPCA), R/univDecomp.R (givenBasis, fpcaBasis), R/univPCA.R (PACE, .PACE), and R/univariateExpansions.R. See also the maintainer's manual.

R's uFPCA is not fdapace. It calls MFPCA::PACE, adapted from refund's fpca.sc, with nbasis=10, pve=0.99, npc=NULL, makePD=FALSE, and cov.weight.type="none". npc overrides pve. It fits the mean with an mgcv spline, forms pairwise empirical residual products using observation counts, removes the diagonal, and smooths the covariance with a tensor spline. It solves the trapezoidally weighted covariance eigenproblem, estimates noise from the middle half of the domain, and calculates conditional scores via $(\Phi_i^\top\Phi_i+\sigma^2\Lambda^{-1})^{-1}\Phi_i^\top(Y_i-\mu_i)$. FDA instead reuses its dense sample covariance or fdapace-style local linear PACE. These smoothing choices and default rank caps can change the result.

For orthonormal expansions, R's exact multivariate eigenproblem is cov(allScores) * outer(allWeights, allWeights), with allWeights repeating $\sqrt{w_j}$ for each univariate component. Nonorthogonal expansions use the block basis Gram matrix through its Cholesky factor; they are outside this API's FPCA-only first step. R has no explicit deterministic sign rule for its original fit; bootstrap functions are aligned to that fit.

To describe R's normalization, set $Q=A/\sqrt{n-1}$. R stores eigenvectors $v_m$ and $h_m=\|Qv_m\|^{-1}$, returns scores $A v_m\sqrt{\nu_m}h_m$, and builds node functions from coefficients $(Q^\top Qv_m)^{(j)}h_m/\sqrt{w_j\nu_m}$. For centered orthonormal expansions, $h_m=1/\sqrt{\nu_m}$ and these reduce to Proposition 5. R fitted values add its mean functions to the resulting score/function expansion. FDA reproduces this centered eigenproblem and uncentered normalization, including for noncentered conditional scores.

The supported strict validation route is type="given", supplying the FDA univariate functions and scores, with explicit ortho=TRUE. R otherwise treats given functions as nonorthogonal. FDA's exporter fixes the observations, different node grids, and first-step arrays. R then independently computes the multivariate eigenvalues, coefficient vectors, node eigenfunctions, scores, and fitted curves. It applies the stated coefficient sign rule. The strict test compares both unit and unequal weights at relative error below 1e-8. A mixed dense/PACE fixture also supplies FDA's nonzero-mean conditional scores via type="given", checking the centered eigenvalues, eigenvectors, normalization factors, scores, functions, and reconstructed curves. Since R's given route uses empirical mean functions while FDA retains the supplied PACE mean, the reference reconstructions subtract R's mean and add FDA's first-step mean. This isolates the multivariate step without changing its scores or functions. CI consumes CSVs and does not run R.

A separate cross-method fixture runs R's own uFPCA end to end (npc=2, other defaults unchanged), on the same three-node dense data. FDA uses two dense components per node. The deterministic curves have linear means and rank-two constant/linear residual spaces; the comparison checks this shared regime rather than general smoother equivalence. The linear mean and constant/linear residuals lie in both smoothers' unpenalized spaces, so this fixture is exact up to numerical error. Joint function signs are aligned once across all nodes. Eigenvalues, functions, scores, and fitted curves use relative tolerance 1e-8 for this cross-method check, as do the strict given-expansion comparisons.

FunctionalDataAnalysis.MFPCA — Type
MFPCA
fit(MFPCA, mfd::MultivariateFunctionalData; ncomponents,
    univariate=(;), weights=ones(ncomponents(mfd)), eigen_tol=1e-10)

Happ and Greven (2018, Proposition 5; doi:10.1080/01621459.2016.1273115) multivariate FPCA. First call marginal fit(FPCA, mfd; univariate...), then diagonalize Ac'Ac/(n-1), where A concatenates the univariate scores with node j multiplied by sqrt(weights[j]) and Ac subtracts column means. This matches cov(allScores) in R MFPCA 1.3-11's exact eigenanalysis. For unit eigenvector c and eigenvalue nu, set Q=A/sqrt(n-1) and h=1/norm(Q*c). Scores are A*c*sqrt(nu)*h; node j's function is phi_j * (Q'Q*c)_j * h/sqrt(weights[j]*nu), following R's uncentered normalization. With mean-zero scores these reduce to A*c and phi_j*c_j/sqrt(weights[j]), with weighted orthonormal functions. For nonzero score means the R-normalized functions need not be orthonormal. Stored node quadrature weights are used on different grids and domains.

ncomponents is required and must be a positive integer, as for M in R MFPCA 1.3-11. It cannot exceed the retained positive score rank; requests are never silently truncated. weights must be finite and strictly positive. The default all ones follows R MFPCA (represented in the data's floating type). The paper's alternative is inverse integrated node variance, 1 / integral(Var(X_j)); it is never selected automatically.

univariate must be a named tuple of keywords for marginal FPCA. Each may be shared or a vector of node-specific values, following MultivariateFPCA. Its empty default reuses the existing dense/PACE routing and all FPCA defaults, including FVE(0.99). This intentionally differs from R's required uniExpansions and its spline-based uFPCA/PACE implementation: no smoother is duplicated. PACE conditional scores can have nonzero sample means: only the covariance eigenproblem centers them, while normalization and score projection use uncentered scores, exactly as in R's default exact route. Unlike marginal PACE eigenvalues, the multivariate eigenvalues describe the sample covariance of these estimated scores.

For common-grid margins, univariate=(; method=:face, face=(; ...)) uses FACE with the defaults and source audit in FPCA. Its shrinkage scores pass through this same joint eigenproblem and prediction interface.

The existing univariate eigenstep is reused with eigen_tol=1e-10, the same package numerical cutoff relative to the largest absolute eigenvalue. Its largest-absolute-entry sign rule is applied to c (first entry breaks ties). Repeated eigenvalues identify only an eigenspace, not a unique orientation. The fit stores eigvals, eigenfunctions (one FPCBasis per node), scores, coefficients, the marginal fit in univariate, copied node weights, IDs, sign rule, and all requested/resolved settings, including R normalization factors and score scales. show displays choices. Exact eigenanalysis is used; approximate eigenanalysis and bootstrap are not implemented. Reconstruction is explicit through reconstruct, matching R's fit=FALSE default. See the manual's Comparison with MFPCA section.

FunctionalDataAnalysis.eigenfunctions — Method
eigenfunctions(f::MFPCA)

Return one stored FPCBasis per node, with a shared multivariate column index. With mean-zero univariate scores, orthonormality holds for the weighted sum of node inner products, rather than for each node separately. With nonzero score means, R's normalization need not give orthonormal functions; see MFPCA. Use deepcopy for independent arrays.

StatsAPI.predict — Method
predict(f::MFPCA, newmfd::MultivariateFunctionalData)

Deprecated compatibility API; prefer project_scores or predict_scores. Predict univariate scores per node using the stored marginal fit, then apply the fitted node weights, multivariate coefficients and R score scales to the uncentered scores (no new-data mean subtraction). Return a subject × component matrix. PACE uses its existing conditional-expectation solver; conditional uncertainties are not propagated across nodes. Node counts must match, and each node must satisfy its univariate prediction requirements.

StatsAPI.reconstruct — Method
reconstruct(f::MultivariateFPCA, scores=scores(f); grid=nothing)

Reconstruct MultivariateFunctionalData from one score matrix per node. A real grid vector applies to every node; a vector of grids applies nodewise. The default uses each training grid. Every grid must be increasing and inside its training domain. Score row counts must agree. Training IDs are retained only if every score matrix is the stored training matrix; copied or new score matrices have no inferred IDs.

source
reconstruct(f::MFPCA, scores=scores(f); grid=nothing)

Return MultivariateFunctionalData with node j equal to its training mean plus scores * eigenfunctions(f)[j]'. grid=nothing uses each training grid; a real vector is shared, or a vector of grids applies nodewise. Grids must be finite, strictly increasing and inside the corresponding training domains. Scores must be finite with one column per multivariate component. Training IDs are retained only for the stored training score object.
