Clustering

Three clustering methods partition a sample of curves:

  • FunctionalKMeans: k-means of the curves in L², or of their FPC scores.
  • KCFC: k-centres functional clustering (Chiou and Li, 2007), which assigns each curve to the cluster whose own FPCA reconstructs it best.
  • FunctionalGaussianMixture: a Gaussian mixture with an unrestricted covariance per cluster, fitted to FPC scores.

All three results are Clustering.ClusteringResults from Clustering.jl, so assignments, nclusters, Clustering.counts, randindex and Clustering.jl's other comparison and quality measures apply directly. Every setting is stored on the result and shown with it. Classification methods are added in a later release.

Example

Three groups of thirty curves differ in their mean and in their dominant mode of variation: group g has standard deviation 1 along mode g and 0.2 along the other two.

using FunctionalDataAnalysis, Random
import StatsAPI
rng = Xoshiro(2026)
grid = collect(range(0, 1; length=41))
group = repeat(1:3; inner=30)
modes = sqrt(2) .* [sinpi(j * t) for t in grid, j in 1:3]
sd(g) = [j == g ? 1.0 : 0.2 for j in 1:3]
curve(g) = 1 .+ grid .+ 1.2 * (g - 2) .* sinpi.(grid) .+ modes * (sd(g) .* randn(rng, 3))
fd = GridFunctionalData(reduce(vcat, [transpose(curve(g)) for g in group]), grid)

k-means of the curves uses the stored quadrature weights for the L² distance. k-means of FPC scores clusters a fitted FPCA.

km = StatsAPI.fit(FunctionalKMeans, fd; k=3, nstart=5, rng)
fpca = StatsAPI.fit(FPCA, fd; ncomponents=FVE(0.9))
scores_km = StatsAPI.fit(FunctionalKMeans, fpca; k=3, nstart=5, rng)
(randindex(km, group)[1], randindex(scores_km, group)[1])
(0.20657567153127204, 0.26172874693458265)

The groups overlap in L², so both k-means partitions agree poorly with them. kCFC starts from k-means of the FPC scores of all curves (here the best of ten starts) and then reclassifies curves by their reconstruction error under each cluster's FPCA (one component per cluster here). Like k-means, it finds a local optimum that depends on its start; initial supplies another one.

kcfc = StatsAPI.fit(KCFC, fd; k=3, cluster_fpca_options=(; ncomponents=1),
    kmeans_options=(; nstart=10), rng)
(kcfc.status, kcfc.iterations, randindex(kcfc, group)[1])
(:converged, 5, 0.7391895601764658)

The Gaussian mixture is fitted to the FPC scores. A range of k selects the number of clusters by BIC.

gm = StatsAPI.fit(FunctionalGaussianMixture, fpca; k=2:4, rng)
(gm.k, gm.selection.values, randindex(gm, group)[1])
(3, [512.1020871479956, 476.2254790450454, 499.8551032803921], 0.6831057621158747)

Cluster centres are functional data: km.centers, scores_km.centers, kcfc.centers (the cluster FPCA means) and gm.centers (the curves of the cluster mean scores) can be evaluated and plotted like any other data, for example with curve_data. predict assigns new curves; for the score-based methods it projects them with project_scores of the stored FPCA.

Departures from the references

  • k-means of curves. fda.usc 2.2.0 kmeans.fd builds its distance matrix once, from every curve to the initial centres (kmeans.center.ini), and the loop in kmeans.fd never recomputes it after kmeans_centers_update. Every pass therefore reassigns curves to the nearest initial centre, the centres stop changing after one update, and the result is the nearest-initial-centre partition with depth-trimmed centres (func.trim.FM, trim=0.05). The package runs Lloyd's algorithm to convergence with plain means, as R's kmeans. With trim=0, fda.usc's centres are plain means, and when one more Lloyd step changes nothing both agree; the validation uses such a case.
  • Seeding. k-means++ replaces fda.usc's best-of-100-random-subsets rule (still available as :spread) because its expected cost is within O(log k) of the optimum (Arthur and Vassilvitskii, 2007).
  • kCFC FPCAs. fdapace's default kCFC options smooth the mean and covariance with GCV bandwidths. The package uses its own FPCA defaults: dense cross-sectional estimates for complete grids (no smoothing) and PACE otherwise. Pass fpca_options and cluster_fpca_options to change them.
  • kCFC initial partition. fdapace calls R kmeans(algorithm="MacQueen") after set.seed(kSeed=123). That stream cannot be reproduced outside R; the package uses Clustering.jl's Lloyd iteration with k-means++ seeding, records the initial labels and accepts an R partition as initial.
  • kCFC on sparse data. fdapace 0.6.0 kCFC stops unless the data are dense, and its GetISEfromFPCA always projects curves by numerical integration (GetINScores), whatever the cluster FPCA's score method. The package projects with each cluster FPCA's own project_scores: the same trapezoidal projection for dense FPCA fits, and PACE conditional expectations for irregular or masked data, which makes kCFC usable for sparse curves. Cluster FPCAs then share the initial FPCA's work grid.
  • Mixture EM. EMCluster stops when the relative log-likelihood change is at most em.eps; near the optimum the log likelihood is flat, so the parameters remain about sqrt(em.eps) from the EM fixed point. On the validation data EMCluster with em.eps=0 stopped after 40 iterations while one more EM step still moved the means by 2e-8. A positive parameter_tol stops on parameter changes instead (zero is rejected, because rounding can keep the iteration from reaching an exact fixed point). Log-likelihood decreases within 100 eps |loglik| are treated as rounding rather than as EMCluster's decrease stop, so a run that starts at the optimum reports :converged. FClust calls emcluster a second time after em.EM with the same criterion; the package runs one EM. EMCluster can count a short-EM start that immediately decreases the likelihood as minus one iteration; the package counts at least one, so initialization always ends. When the final EM degenerates (a component with posterior weight sum at most the number of scores, or a singular covariance), the package redraws the em.EM initialization within restarts, as EMCluster does for a small final class, and throws after the last attempt instead of producing a singular covariance. Initialization fails, and counts as an attempt, when 1000 random partitions all have a class of at most that many curves or every short run degenerates. A k with more classes than the curves can fill fails at once. In a range of k, a k that fails in every attempt is skipped with criterion Inf and listed in selection.degenerate. The fit throws only if every k fails.
  • Selecting the number of mixture components. FClust fits a fixed k. A range of k uses EMCluster's em.bic (or em.aic), the criterion of its runemEMcluster, with BIC as the default because it is consistent for the number of components (Keribin, 2000).

Implementation

k-means uses Clustering.jl kmeans on the curves scaled by the square roots of the quadrature weights (or multiplied by the Cholesky factor of the basis Gram matrix), so that Euclidean distances are L² distances. The Gaussian mixture's E and M steps are GaussianMixtures.jl em! on a full-covariance GMM; the EMCluster initialization, stopping rules and decrease guard wrap single em! steps. kCFC is implemented in the package and reuses fit(FPCA, ...), project_scores and the FPCA reconstruction at observation times used by residuals.

Reference source audit

Versions audited: fdapace 0.6.0 (kCFC, FClust, GetISEfromFPCA, GetINScores, List2Mat), fda.usc 2.2.0 (kmeans.fd, kmeans.center.ini, kmeans_assig_groups, kmeans_centers_update, metric.lp) and EMCluster 0.2-18 (em.EM, init.EM, emcluster, assign.class and the C routines shortems, randomEMinit, initials, shortemcluster, emcluster, mstep).

  • fdapace FClust defaults to cmethod="EMCluster" with k=3 and FPCA options methodMuCovEst="smooth", FVEthreshold=0.9 and GCV bandwidths. It clusters FPCA(...)$xiEst with emcluster(xi, em.EM(xi, nclass=k), assign.class=TRUE).
  • EMCluster fits one unrestricted covariance per component. em.EM draws k distinct observations as centres, assigns every observation to the nearest one and starts from class means, covariances with denominator n_c - 1 and proportions n_c/n, redrawing while a class has at most p members; short EM runs (gain relative to the run's total gain at most short.eps=0.01) share a budget of short.iter=200 iterations, and the best start (>=, so the last on ties) is run by emcluster until the relative log-likelihood change is at most em.eps=1e-6 or em.iter=1000 iterations; a decrease reverts the last step. The R wrapper repeats the whole initialization up to min.n.iter=10 times while a final class has fewer than p+1 members, and warns if it fails. Labels maximize the posterior probability.
  • fdapace kCFC has k=3, kSeed=123, maxIter=125, FVE thresholds 0.9 and 0.7 and refuses sparse data. Its initial step is kmeans(xiEst, k, algorithm="MacQueen", iter.max=maxIter); it stops if a cluster has three or fewer curves. Each iteration computes the trapezoidal ISE of every curve under every cluster FPCA, takes the minimum, stops for a lost cluster, for a cluster of at most 0.01n or three curves, or when the partition equals an earlier iteration's (not the initial one), and otherwise refits the cluster FPCAs. iterToConv is the iteration count minus one; the returned FPCAs are those fitted to the previous partition.
  • fda.usc kmeans.fd is described under the departures above; its default distance is metric.lp (trapezoidal L²) and its default centre is the FM depth-trimmed mean with trim=0.05.

Validation

test/clustering.jl compares, at relative error below 1e-8, on three groups of twelve noise-free curves whose deviations vanish at both endpoints (where fdapace's rectangular and the package's trapezoidal eigenproblems coincide):

  • FunctionalKMeans with seed curves against fda.usc 2.2.0 kmeans.fd (trim=0): labels, centres and metric.lp distances to the seeds;
  • FunctionalKMeans of FPC scores against stats::kmeans(algorithm="Lloyd") from the same seed rows: labels, centres and within-cluster sums of squares, together with the FPC scores and eigenvalues against fdapace's dense cross-sectional FPCA;
  • KCFC against fdapace 0.6.0 kCFC with cross-sectional FPCAs, starting from kCFC's recorded initial labels: final labels, iteration count, every intermediate partition, the final n × k ISE matrix and each cluster FPCA's mean and eigenvalues;
  • FunctionalGaussianMixture from supplied labels against the fixed point of EMCluster 0.2-18's own E and M steps (parameter_tol=1e-12): proportions, means, covariances, posterior probabilities, labels, log likelihood, AIC and BIC. With the default tol the labels agree and the log likelihood is within the relative tolerance.

Random initializations (k-means++, em.EM, fdapace's seeded MacQueen k-means) are not compared, because they depend on each language's random number generator; their outputs are recorded so that a partition can be supplied. Sparse kCFC is checked by recovering a known two-cluster partition. Mixture initialization and BIC selection are checked on three groups of one-dimensional scores six standard deviations apart, where the true partition and k = 3 are recovered whatever the random starts.

Recreate the references with Rscript test/reference/clustering_m8.R (R 4.5.1; fdapace 0.6.0, fda.usc 2.2.0, EMCluster 0.2-18). No R installation is needed to use the package or run its tests.

FunctionalDataAnalysis.FunctionalKMeans — Type
FunctionalKMeans
fit(FunctionalKMeans, fd::Union{GridFunctionalData,BasisFunctionalData}; k=2,
    init=:kmpp, nstart=1, maxiter=100, tol=1e-6, rng=Random.default_rng())
fit(FunctionalKMeans, f::FPCA; k=2, kwargs...)

k-means clustering (Lloyd's algorithm, from Clustering.jl kmeans) of curves under the L² distance or of the FPC scores of a fitted FPCA.

Curves: complete grid data use the stored quadrature weights w, so the squared distance between curves x and y is sum(w .* (x .- y).^2); basis data use the exact basis Gram matrix. Masked grid and irregular data throw: interpolate them to a complete grid, or cluster FPC scores. Scores: the Euclidean distance between score vectors, which equals the L² distance between the reconstructed curves because the eigenfunctions are orthonormal under the work-grid weights. Centres are cluster means.

Defaults and their sources:

  • k=2: fda.usc 2.2.0 kmeans.fd (ncl=2).
  • init=:kmpp: k-means++ seeding (Arthur and Vassilvitskii, 2007, expected cost within O(log k) of the optimum), Clustering.jl's default. This departs from fda.usc's method="sample", available as init=:spread: among min(100, binomial(n, k)) random sets of k curves, take the first with the largest sum of pairwise L² distances. init=:rand draws k distinct curves uniformly, as R's kmeans does for a number of centres. An integer vector gives the seed curves directly (fda.usc's ncl vector) and requires nstart=1.
  • nstart=1: R kmeans and fda.usc use one start. Several starts keep the smallest total cost (the first on ties); all start costs are stored.
  • maxiter=100: fda.usc max.iter.
  • tol=1e-6 is relative: Clustering.jl stops when the absolute change of the total cost is below tol times the total sum of squares about the overall mean, making the rule invariant to the units of the data (Clustering.jl's own tol is absolute). The resolved absolute value is stored.

fda.usc 2.2.0 kmeans.fd computes its distance matrix once, to the initial centres, and never updates it, so its result is the nearest-initial-centre partition followed by one update of depth-trimmed means (func.trim.FM, trim=0.05). The package iterates Lloyd's algorithm to convergence with plain means; see the clustering documentation for the audit.

Clustering.jl re-seeds an empty cluster at random during the iteration; a final empty cluster throws. All settings are stored and shown.

The result is a Clustering.ClusteringResult, so assignments, nclusters, Clustering.counts and randindex apply. Fields:

  • space: :L2 (curves) or :fpc_scores.
  • k, assignments, counts.
  • centers: cluster means as functional data. Grid data give a GridFunctionalData on the data grid, basis data a BasisFunctionalData in the data basis and FPC scores the FPCA reconstruction of the mean scores.
  • center_coordinates: k × d cluster means of grid values, basis coefficients or scores.
  • costs: squared L² (or score) distance of each curve to its own centre; withinss sums them by cluster and totalcost over all curves.
  • iterations, converged: from the chosen start's Lloyd iteration.
  • seeds: the chosen start's initial centre indices; start_costs holds every start's total cost and best_start the chosen one (the first minimum).
  • fpca: the FPCA whose scores were clustered, or nothing.
  • settings: every option, including the resolved numerical tolerance.

FunctionalDataAnalysis.KCFC — Type
KCFC
fit(KCFC, fd::Union{GridFunctionalData,IrregularFunctionalData}; k=3,
    initial=nothing, fpca_options=(; ncomponents=FVE(0.9)),
    cluster_fpca_options=(; ncomponents=FVE(0.7)), maxiter=125,
    kmeans_options=(;), rng=Random.default_rng())

k-centres functional clustering (Chiou and Li, 2007), following fdapace 0.6.0 kCFC (also FClust(cmethod="kCFC")):

  1. Fit FPCA to all curves with fpca_options.
  2. Initial partition: initial labels in 1:k, or k-means of the FPC scores with FunctionalKMeans (maxiter=maxiter and rng unless kmeans_options sets them). A cluster of at most three curves throws.
  3. Fit an FPCA with cluster_fpca_options to each cluster.
  4. Reclassify every curve to the cluster whose FPCA reconstructs it with the smallest integrated squared error (ISE, trapezoidal rule over the curve's observation times; ties go to the lowest index). Stop when the partition repeats any earlier reclassification (:converged), loses a cluster (:lost_cluster), has a cluster of at most max(0.01n, 3) curves (:tiny_cluster), or after maxiter steps (:maxiter). Otherwise refit the cluster FPCAs and repeat. The last three statuses warn, as in fdapace.

Reconstruction uses each cluster FPCA's own score solver through project_scores. For dense FPCA fits this is the trapezoidal projection fdapace's GetINScores uses, so results agree with fdapace given the same FPCAs. For irregular or masked data it is the PACE conditional expectation, which extends kCFC to sparse designs; fdapace 0.6.0 stops for sparse data. When the initial FPCA uses PACE and cluster_fpca_options has no grid, cluster FPCAs use the initial FPCA's work grid, so every curve lies inside every cluster's grid. Every curve needs at least two observations.

Defaults and their sources: k=3, maxiter=125, FVE thresholds 0.9 (initial) and 0.7 (clusters) are fdapace 0.6.0 kCFC's. Departures: the FPCAs use the package's fit(FPCA, ...) defaults (dense cross-sectional estimates on complete grids, PACE otherwise), whereas fdapace's default options smooth the mean and covariance with GCV bandwidths; pass fpca_options/cluster_fpca_options (for example method=:pace) to smooth. fdapace's initial clustering is R kmeans(algorithm="MacQueen") after set.seed(123), which cannot be reproduced outside R; the package uses Clustering.jl's Lloyd iteration with k-means++ seeding and records the initial labels, so an R partition can be supplied as initial.

The result is a Clustering.ClusteringResult. Fields:

  • k, assignments, counts: final partition.
  • initial_assignments, initial_fpca (FPCA of all curves) and initial_clustering (the FunctionalKMeans of its scores, or nothing when initial labels were supplied).
  • fpcas: the cluster FPCAs used in the final reclassification, in cluster order. As in fdapace, these were fitted to the previous partition.
  • centers: their mean functions as GridFunctionalData on the common grid.
  • costs: n × k integrated squared reconstruction errors of the final step.
  • history: the partition produced by every reclassification step.
  • iterations (fdapace iterToConv) and status: :converged, :maxiter, :lost_cluster or :tiny_cluster.
  • settings: every option.

FunctionalDataAnalysis.FunctionalGaussianMixture — Type
FunctionalGaussianMixture
fit(FunctionalGaussianMixture, fd::AbstractFunctionalData;
    fpca_options=(; ncomponents=FVE(0.9)), kwargs...)
fit(FunctionalGaussianMixture, f::FPCA; k=3, init=:emem, criterion=BIC(),
    maxiter=1000, tol=1e-6, parameter_tol=nothing, short_iter=200,
    short_tol=0.01, restarts=10, rng=Random.default_rng())

Model-based clustering in the FPC subspace, following fdapace 0.6.0 FClust(cmethod="EMCluster"): fit FPCA to all curves (FVE 0.9 by default, as in FClust) and a k-component Gaussian mixture with unrestricted covariance per component (EMCluster's only model, mclust "VVV") to the scores. EM steps are GaussianMixtures.jl em!; the initialization and stopping rules follow EMCluster 0.2-18:

  • init=:emem is EMCluster's em.EM: repeat random starts (k distinct curves as centres, nearest-centre partition, class means and covariances with denominator n_c - 1, proportions n_c/n; partitions with a class of at most K curves are redrawn) followed by short EM runs that stop when the log-likelihood gain relative to the start's total gain is at most short_tol=0.01, until short_iter=200 short iterations are spent. Each start counts at least one iteration, so the loop ends; EMCluster can count a start as minus one. The start with the largest log likelihood (the last on ties, as in EMCluster) is run to convergence.
  • init may instead be initial labels in 1:k, converted to parameters as above (for supplied initializations and reference comparisons).
  • EM stops when the relative log-likelihood change is at most tol=1e-6 (EMCluster em.eps), after maxiter=1000 iterations (em.iter), or when the log likelihood would decrease; that step is reverted, as in EMCluster. Decreases within 100 eps |loglik| count as rounding, not as decreases. The log-likelihood rule leaves parameters about sqrt(tol) from the EM fixed point; with a positive number parameter_tol, EM instead stops when no weight, mean or covariance entry changes by more than parameter_tol. (Zero is not allowed: rounding can keep an EM step from returning exactly the same parameters.) EMCluster with em.eps=0 stopped while one more EM step still moved means by 2e-8 (test/reference/clustering_m8.R).
  • restarts=10: if a final cluster has at most K curves, or the final EM degenerates (a component's posterior weight sum falls to at most K, or a covariance becomes singular), :emem is repeated up to this many times in total (EMCluster min.n.iter). After the last attempt a degenerate EM throws, and a small cluster is kept with status :unstable and a warning.

FClust calls emcluster a second time with the same criterion after em.EM, which adds at least one EM iteration; the package runs one EM. Random draws use rng; EMCluster's use R's generator and cannot be reproduced. With supplied labels, a component whose posterior weight sum falls to at most K throws, rather than producing a singular covariance.

k=3 is FClust's default. A vector or range of k fits each value with init=:emem and keeps the smallest criterion (AIC() or BIC(); the first on ties), using EMCluster's em.aic/em.bic with dof = kK + kK(K+1)/2 + k - 1. A k that fails in all restarts attempts gets criterion Inf and is listed in selection.degenerate. A failure is a degenerate final EM, an initialization that finds no partition into classes of more than K curves in 1000 draws, or every short run degenerating. A k with k(K + 1) > n fails without any attempt. The fit throws, naming the reason for each k, only if every k fails. FClust has no selection; BIC is the default because it is consistent for the number of mixture components (Keribin, 2000).

The result is a Clustering.ClusteringResult. Fields:

  • k, assignments (largest posterior probability), counts, posterior (n × k).
  • weights, means (k × K in score space), covariances (one K × K matrix per component).
  • loglikelihood, aic, bic, dof (number of free parameters).
  • iterations, status (:converged, :maxiter, :likelihood_decrease; :unstable when a final cluster has at most K curves).
  • fpca, centers (cluster mean curves mean + means * eigenfunctions').
  • initialization: the method and, for :emem, the number of short-EM starts and their best log likelihood.
  • selection: the criterion table when k was a range (k, values, loglikelihood (NaN when degenerate), dof, degenerate, chosen).
  • settings: every option.
