Noise-variance estimators (issue #17)

The SmoothedCovariance keywords are noise_method=:rotated|:surface_diagonal and noise_interval=:full|:middle_half; the defaults (first in each pair) were chosen by the issue #17 benchmark on USC Discovery (48 designs × 500 replicates): the rotated diagonal over the full interval had the lowest MSE in 41 of 48 cells, and both surface estimators had much larger upward bias. Raw estimates and truncation flags remain available. The rotated calculation follows the source-audited fdapace 0.6.0 PC_CovE calculation at fixed bandwidths; it does not alter the stored covariance surface. The source audit gives the exact rotation, polynomial columns, bandwidths, cut rule, and departures.

All new fit choices are stored in noise_details and displayed by show. The details include method, interval, domain, bounds, nominal length, boundary rule, integration grid, fitted latent diagonal, and rotation settings. The raw-square bandwidth/CV details are also retained.

Reference values

The fixed-bandwidth reference fixture uses R 4.5.1 / fdapace 0.6.0. Recreate it from the repository root with:

Rscript test/reference/fdapace_m5_sigma2.R

The comparisons cover 48 combinations of weighting, kernel, bandwidth, grid, and interval. Raw variance and both fitted diagonals are compared at relative error below 1e-8. The source audit describes the quantities compared and the deliberate departures from fdapace.

Discovery benchmark

The reference run on 25 October 2026 used Julia 1.13.2 and FunctionalDataAnalysis 0.1.0, source commit d26162c17fe1b221d0648023ca5b69728095abc1. It covered 48 configurations with 500 replicates each. All 120,000 estimates succeeded. The complete CSV results and per-cell table retain every configuration and estimator. The results README records provenance and recreation instructions.

Benchmark settings

These are explicit harness settings. They do not add package defaults:

  • Process: mean 1+t, three normalized Fourier functions, eigenvalues [1,.5,.25]; variance ratio rather than standard-deviation ratio.
  • Grid/kernel: 51 equally spaced observed-range points and Gaussian, matching audited PACE defaults. Dense subjects share 50 equally spaced times.
  • CV: five curve folds, mean candidates [.025,.05,.1] and covariance candidates [.05,.1,.2] times the observed range. Mean and covariance use the same deterministic split. Covariance CV is conditional on the supplied full-sample mean, as in the existing package. Raw-square bandwidth inherits the selected covariance bandwidth.
  • Pairing/seeds: MersenneTwister seeds shared across weighting and bandwidth choices. The exact Julia version is recorded because streams can change.
  • Packaging: one configuration contains all five estimators, so 48 tasks cover 240 estimator cells. Each task writes one summary row plus raw/failure companions. Exact duplicate aggregation preserves weighted fits and CV losses; it never snaps times or discards pairs.
  • Projected reference: all positive weighted eigencomponents with FGM's 100eps(Float64) relative cutoff and its arithmetic index-window average. Common smoothed inputs isolate the diagonal rule. This is a benchmark-only comparison, not end-to-end FGM equivalence.
  • Failures: no replacement or silent dropping. Fit ArgumentErrors are recorded; successful-fit moments are explicitly conditional if any fail. Unexpected errors abort. Variance uses R-1; MSE uses R. Output overwrite is rejected.
  • Discovery template: one CPU / 2 GB / 24 hours per task, array concurrency eight, one Julia/BLAS thread. Module, project, configurations and outputs are variables. The owner selects current allocation/partition and resource budget before a new run.
