Uncertainty

fitted_bands describes uncertainty in individual latent PACE or FACE curves. mean_bands describes uncertainty in the population mean estimated from independent curves. These have different targets and assumptions.

Individual PACE curves

bands = fitted_bands(pace; alpha=0.05, coverage=:interval, curves=[1, 3])
simultaneous = fitted_bands(pace; coverage=:band)
# After loading Plots:
band_plot(bands)

For curve i, the stored conditional score covariance is Ωᵢ. The variance of the prediction error for the selected-K latent curve is

\[v_i(t) = \phi_K(t)^\mathsf{T}\Omega_i\phi_K(t).\]

Pointwise intervals are the reconstructed curve plus or minus quantile(Normal(), 1-alpha/2) * sqrt(vᵢ(t)). Simultaneous bands replace the normal critical value with sqrt(quantile(Chisq(K), 1-alpha)). The package computes these critical values without a new runtime dependency. Under the conditional Gaussian model, the score ellipsoid provides at least nominal coverage for the truncated curve. Its envelope can be conservative. It is simultaneous within one curve and one node; it does not adjust for selecting multiple curves or nodes.

The mean, eigenfunctions, covariance, noise variance and component selection are treated as fixed estimates. Omitted-component bias and uncertainty in these estimates are not included. Measurement noise is not added to the band: the target is a latent trajectory, not a future noisy observation. This is the model-based fitted-curve uncertainty described by refund, rather than a corrected band that accounts for estimating the FPCA model. Dense integration scores do not carry conditional covariance. Fit with method=:pace to request this calculation.

FittedBands holds copied grid, fitted, lower, upper, and variance arrays. Each row follows curves. It records alpha, coverage, selected ncomponents, score method, and critical_value. A custom grid uses the same explicit piecewise-linear mean and eigenfunction evaluation as reconstruct. fitted_bands(multivariate_fit) returns (; nodes), with separate node results. Joint Happ–Greven MFPCA uncertainty is not implemented. The stored settings record the selected-score variance source, latent target, interpolation and PSD cleanup rule. Negative conditional eigenvalues are clipped only within 100eps(T) * max(1, maximum(abs, eigenvalues)), where T is the score-covariance element type; larger negative values throw.

FACE curves

FACE supports the same pointwise fitted_bands(model; coverage=:interval) interface. Its posterior covariance agrees with its shrinkage scores and corrects refund 0.1-40's multiplication by eigenvalues in place of their inverses. The formula, numerical example, and source audit are on the FPCA page. Masked training values are treated as completed observations, so these intervals exclude imputation uncertainty. FACE coverage=:band throws; simultaneous FACE bands are outside this interface.

The mean

using Random
m = StatsAPI.fit(SmoothedMean, fd; grid=workgrid, bandwidth=h)
uncertainty = mean_bands(fd, m; B=1000, rng=MersenneTwister(42))
# Recreate the bootstrap from its stored initial RNG state:
repeated = mean_bands(fd, m; B=uncertainty.B, rng=uncertainty.rng_state)
# After loading Plots:
band_plot(uncertainty; coverage=:band)

The bootstrap samples whole curves with replacement, retaining all their observed times and within-curve dependence. It refits with the stored scalar bandwidth, kernel, polynomial degree, weighting and work grid. Bandwidth selection is not repeated. Supply the original training data. A refit must reproduce the stored mean; this compatibility check cannot certify data provenance.

bootstrap_replicates is a descriptive alias for B: it counts whole-curve resamples, with default 1000. Supply at most one name. For example, mean_bands(fd, m; bootstrap_replicates=1000, rng=MersenneTwister(42)) has exactly the same draws and endpoints as the B=1000 form with that RNG. Both names are bootstrap-only; the stored result field remains B.

coverage=:interval gives pointwise percentile intervals from bootstrap means, with R type-7 empirical quantiles. coverage=:band uses

\[q^*_{1-\alpha} = \operatorname{quantile}_{1-\alpha} \left\{\max_{t\in\mathcal G} \frac{|\widehat\mu_b^*(t)-\widehat\mu(t)|}{s^*(t)}\right\}_{b=1}^B, \qquad \widehat\mu(t)\ \pm\ q^*_{1-\alpha}s^*(t),\]

where s*(t) is the sample standard deviation of the B bootstrap means. coverage=:both returns both types. The original fitted mean centers the sup-t deviations; no nested bootstrap is used. A zero standard error gives a zero standardized deviation only if every replicate equals the original mean there. Otherwise the simultaneous calculation throws.

The grid is held fixed even when a resample has a narrower observed range. Kernel estimates on that grid must remain defined. An undefined replicate throws with its number; there are no retries, dropped draws or removed grid points. A large enough bandwidth may be needed for sparse designs.

The RNG is copied, its initial state is stored, and the caller's state is preserved. MeanBands stores the B refitted means, bootstrap standard errors, original mean and copied smoother, interval/band endpoints, RNG state and settings. RNG reproduction requires the same Julia/RNG implementation. The RNG must support state copying; RandomDevice is rejected.

Both intervals and bands require independent subjects and negligible smoothing bias relative to sampling error. Simultaneity applies to the supplied finite grid. Degras (2011) supplies functional mean-band theory for fine-grid data; the whole-curve bootstrap here is a separate calibration and is not a theorem for arbitrary sparse designs. Coverage should be checked for the design and smoothing regime being used.

Analytic pointwise option

analytic = mean_bands(fd, m; method=:sandwich)

KernelSmoothing supports curve-cluster variance. This option uses ClusterVariance(1), its default CR1 adjustment, with subjects as clusters. It reuses the original smoother's settings and returns normal intervals around the stored mean using conventional cluster standard errors. No robust bias correction is applied, so smoothing bias must still be small. A window with fewer than two contributing clusters has undefined variance and throws. No window or grid point is dropped.

Only coverage=:interval is available for this method and is its default. Explicit B, bootstrap_replicates and rng throw because no resampling occurs. The result has B=0, rng_state=nothing, an empty bootstrap matrix, and records CR1, conventional inference, curve clusters and minobs=0. Analytic simultaneous mean bands are not implemented.

The fdapace source audit records its formulas, rank behavior and the reference fixture's explicit corrections. The golden CSVs use R 4.5.1 and fdapace 0.6.0. Recreate them with Rscript test/reference/fdapace_m5_bands.R; fitted curves and both types of endpoints are compared at relative error below 1e-8. The critical-value fixture also checks central and tail χ² quantiles against R's qchisq.

References:

  • Yao, Müller and Wang (2005), Functional Data Analysis for Sparse Longitudinal Data, equations (7)–(8), Theorem 4 (pointwise), Theorem 5 (simultaneous).
  • Degras (2011), Simultaneous confidence bands for nonparametric regression with functional data, Statistica Sinica 21, 1735–1765.
  • refund 0.1-40, fpca.sc, model-based curve covariance; model-estimation correction is discussed in Goldsmith, Greven and Crainiceanu (2013), cited there.

API

FunctionalDataAnalysis.FittedBands — Type
FittedBands

Result of fitted_bands. fitted, lower, upper, and variance are curve-by-grid matrices. curves records training indices in row order. The result stores copied coordinates, alpha, coverage, critical value, selected component count, and score method. Variance concerns latent selected-K curves, conditional on the fitted model; it excludes new measurement error.

source
FunctionalDataAnalysis.MeanBands — Type
MeanBands

Mean uncertainty result from mean_bands. fitted is the original mean; interval and band hold (; lower, upper) vectors, or nothing when not requested. standard_error is the bootstrap sample standard deviation. bootstrap stores B rows of refitted means. rng_state is a copy of the RNG before drawing; mean is a copied SmoothedMean. Sandwich results instead store cluster-robust standard errors, zero bootstrap rows, B=0, and rng_state=nothing. All settings are retained.

FunctionalDataAnalysis.fitted_bands — Function
fitted_bands(f::FPCA; alpha=0.05, coverage=:interval, grid=f.grid, curves=:all)
fitted_bands(f::MultivariateFPCA; alpha=0.05, coverage=:interval, grid=nothing, curves=:all)

Conditional Gaussian prediction intervals for training latent curves, using phi(t)' * score_covariances(f)[:,:,i] * phi(t). :interval uses the two-sided normal critical value; :band uses sqrt(chisq(K, 1-alpha)) (Yao, Müller and Wang, 2005, equations 7–8; Theorems 4–5). K is the selected rank. These match fdapace 0.6.0 fitted.FPCA's named methods and formulas; that function defaults to no intervals (alpha=NULL) and, when requested, band. This API defaults to alpha 0.05 and pointwise intervals per milestone 5.

The work grid and all curves are used by default, as in fdapace. Grid and curve selection follow reconstruct and curve_data. Return FittedBands, or (; nodes) for multivariate fits, with separate coverage per curve and per node, not joint across subjects or nodes. Dense integration scores have no conditional variance and throw; use method=:pace when fitting. No uncertainty in estimated mean, covariance, eigenfunctions or truncation is included. Omitted components are not covered. Roundoff-negative conditional eigenvalues are clipped within 100eps(T)*max(1, maximum(abs, eigenvalues)), a package numerical tolerance recorded in settings; materially indefinite covariances throw.

Common-grid FACE supports coverage=:interval with the posterior covariance consistent with its shrinkage scores. For grid eigenfunctions Phi, eigenvalues Lambda and positive noise sigma2, its curve variance is the diagonal of sigma2 * Phi * (Phi'Phi + sigma2 * inv(Lambda))^(-1) * Phi'. This corrects refund 0.1-40's use of its internal scaled eigenvalues in place of the inverse score covariance; see the FPCA page for its scale. For masked training data, filled observations are treated as complete, as in refund; imputation uncertainty is excluded. Sparse FACE uses the same Phi * score_covariance * Phi' projection with its BLUP covariance, which conditions on the full positive spline covariance as in face 0.1-8. Simultaneous FACE bands throw.

FunctionalDataAnalysis.mean_bands — Function
mean_bands(fd, m::SmoothedMean; method=:bootstrap, alpha=0.05,
    B=nothing, bootstrap_replicates=nothing,
    coverage=(method === :sandwich ? :interval : :both), rng=nothing)

Resample whole independent curves with replacement and refit the pooled mean with m's stored grid, bandwidth, kernel, degree and weighting. Bandwidth selection is not repeated. fd must be the data used to fit m; this is checked by refitting once. Undefined bootstrap fits throw with the replicate number; no draws or grid points are dropped. Grid and irregular data, including masked grids, are supported. At least two curves and B >= 2 are required. bootstrap_replicates is a descriptive alias for B, the number of whole-curve resamples. Supply at most one; omitting both selects 1000 for bootstrap inference. The stored result field remains B.

:interval gives pointwise percentile intervals (R type-7 quantiles, as in fdapace 0.6.0 GetMeanCI). :band gives a gridwise simultaneous sup-t band: the (1-alpha) quantile of maximum(abs.(mstar-m.values)./se) multiplies the bootstrap standard deviation se at each grid point. :both returns both. A zero se gives zero standardized deviation only when all replicates equal the original estimate there; otherwise a requested sup-t band throws.

For method=:sandwich, only coverage=:interval is supported: use KernelSmoothing's ClusterVariance(1) (CR1, its cluster default), with curves as clusters, conventional standard errors, and normal critical values around the stored mean. No robust bias correction is applied. Explicit B, bootstrap_replicates and rng are bootstrap-only and throw for this method.

Return MeanBands. Bootstrap B=nothing resolves to 1000 and rng=nothing to Random.default_rng(). The RNG must support state copying (RandomDevice is not supported). It is copied before use, leaves the caller's state unchanged, and its initial state is stored for recreation. Alpha 0.05, B=1000, :both, and the default RNG follow milestone 5's Gap Map. Curve-level resampling preserves within-curve dependence. See Degras (2011), Simultaneous confidence bands for nonparametric regression with functional data, for functional mean-band theory; this curve bootstrap is not its Gaussian-process calibration. Coverage concerns the supplied finite grid and requires negligible smoothing bias. No continuum or arbitrary sparse-design guarantee is claimed. Sandwich intervals also require negligible smoothing bias.

FunctionalDataAnalysis.band_data — Function
band_data(b::FittedBands)
band_data(b::MeanBands; coverage=b.coverage)
band_data(b::NamedTuple{(:nodes,)})

Return copied plotting coordinates and settings for precomputed uncertainty results. No model fitting or resampling occurs. Fitted results contain curve-by-grid values, lower, and upper matrices plus curves and grid. Mean results contain one row per band type. For a mean result holding both types, coverage=:both returns two series, labeled by types; select :interval or :band to display one. Requesting an uncomputed type throws. Multivariate fitted results return (; nodes) for separate node panels.

FunctionalDataAnalysis.band_plot — Function
band_plot(b; kwargs...)
band_plot(b::MeanBands; coverage=b.coverage, kwargs...)

Plot precomputed fitted_bands or mean_bands results as ribbons around their fitted curves or means, using band_data. For mean results coverage selects a computed type; the default shows all computed types. Multivariate results use one panel per node. Load Plots.jl first; kwargs override plot attributes. Default ribbon opacity is 0.2, a package display choice. No bootstrap is run by plotting.
