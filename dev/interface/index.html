Interface

The package implements grid, irregular, basis and multivariate functional data, smoothing, decompositions and uncertainty summaries. Curves are rows; components and evaluation points are columns where a matrix is returned.

Fitting and prediction

fit and predict extend StatsAPI. Per-curve smoothers return functional data directly, while pooled smoothers return dedicated mean/covariance summaries and decompositions return model objects. The table records the current result contracts. Here n is the new subject count, K a selected component count, and K_j the selected count for node j.

For raw univariate data, method=:auto selects dense FPCA for complete common-grid data and PACE for irregular or masked data. method=:face is explicit: grid input selects common-grid FACE; irregular input selects sparse FACE. It is not chosen automatically by sampling density. See FPCA, multivariate FPCA, cross-structure and CCA for route-specific settings and restrictions. Derivative results come from derivative(model, ...), rather than fit; they support reconstruction as described under derivatives.

Generic ownership and storage

nobs, fit, predict and reconstruct are StatsAPI generics. StatsAPI 1.8 or newer is required for the shared reconstruct binding. Existing FDA reconstruction calls and return values are unchanged; qualified imports now identify the same generic:

import FunctionalDataAnalysis
import StatsAPI: fit, predict, reconstruct
# reconstruct(model) == FunctionalDataAnalysis.reconstruct(model)

evaluate remains owned by FunctionalDataAnalysis. When also loading MultivariateStats or another package exporting that name, use FunctionalDataAnalysis.evaluate(data, times) or import it explicitly. eigvals and svdvals extend LinearAlgebra's generics.

FSVD exposes svdvals, fve, left_functions, right_functions, left_scores, right_scores, nobs and ncomponents. CCA exposes canonical_weights, canonical_variates, canonical_correlations, squared_canonical_correlations, nobs and ncomponents. Array accessors return the fit's own storage; modifying that storage changes the fit. Use copy for arrays and deepcopy for basis-data weights. The CCA paired accessors return named tuples with left and right entries referencing the stored objects. Accessor docstrings give dimensions and ownership; CCA's penalized correlations generally differ from empirical correlations of its variates.

Data interface

FunctionalDataAnalysis.AbstractFunctionalData — Type
AbstractFunctionalData{T<:AbstractFloat}

A collection of n curves on a common domain, with floating-point type T. Concrete univariate types are GridFunctionalData, IrregularFunctionalData and BasisFunctionalData. MultivariateFunctionalData collects components for the same subjects. eltype(fd) is the numerical scalar type.

FunctionalDataAnalysis.AbstractBasis — Type
AbstractBasis

A basis for representing functions on a common domain. The interface is nbasis(b), domain(b), basis_matrix(b, t; derivative), gram(b) and penalty(b, order).

FunctionalDataAnalysis.evaluate — Function
evaluate(fd, t)

Evaluate each curve in fd at the points in t. Return an nobs(fd) × length(t) matrix, with curves in rows and evaluation points in columns.

Basis data evaluate exactly and accept derivative=0. Grid and irregular data require an explicit PiecewiseLinear() or NoInterpolation() evaluator. Piecewise-linear evaluation returns NaN outside a curve's observed range; exact lookup throws at any unobserved time. Query points must be finite.

This generic is owned by FunctionalDataAnalysis. Use FunctionalDataAnalysis.evaluate when also loading another package that exports evaluate, such as MultivariateStats.

Multivariate evaluation on a common point vector returns an nobs × ncomponents × length(t) array and rejects points outside any component's domain. A vector of point vectors returns one matrix per component. Pass an evaluator whenever any component is raw data; it is ignored for basis components.

source
FunctionalDataAnalysis.sampling_design — Function
sampling_design(fd)

Return :regular for complete grid data or basis data. For masked grids and irregular data, return :dense_irregular when the median observation count per curve is at least threshold (default 20), otherwise :sparse. The threshold must be finite and positive; an even sample uses the average of the two middle counts.

Multivariate data return a Vector{Symbol}, passing threshold to each component. For example, all(==(:regular), sampling_design(mfd)) checks that all components are regular; there is no aggregate multivariate design.

source
FunctionalDataAnalysis.quadrature_weights — Function
quadrature_weights(grid)

Trapezoidal integration weights on a finite, strictly increasing grid of at least two points. The weights sum to last(grid) - first(grid).

The result preserves the input's floating-point type. Integer grids produce Float64 weights. Invalid grids throw an ArgumentError.
