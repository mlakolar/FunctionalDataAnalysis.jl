Classification

Supervised classification assigns curves to known classes. Four classifiers follow fda.usc 2.2.0: k nearest neighbours (FunctionalKNN), the maximum-depth classifier (DepthClassifier), the DD-classifier (DDClassifier) and discriminant analysis on FPC scores (FunctionalLDA, FunctionalQDA). All are fitted with fit(Type, x, y; ...), where y holds one label per curve of any sortable type. The classes are the sorted distinct labels, stored in classes. predict(f, newx) returns labels, predict(f, newx; type=:probability) the class probabilities (columns in classes order) where the method defines them, and fitted(f) the training labels.

using FunctionalDataAnalysis, Random
import StatsAPI: fit
rng = Xoshiro(2024)
grid = collect(range(0, 1; length=31))
n = 60
labels = repeat(["low", "high"], n ÷ 2)
shift = [label == "high" ? 0.8 : 0.0 for label in labels]
level = shift .+ 0.4 .* randn(rng, n)
amplitude = 0.5 .+ 0.2 .* randn(rng, n)
values = [level[i] + amplitude[i] * sin(2pi * t) + 0.05 * randn(rng) for i in 1:n, t in grid]
train = GridFunctionalData(values[1:50, :], grid)
test = GridFunctionalData(values[51:60, :], grid)
ytrain, ytest = labels[1:50], labels[51:60]
knn = fit(FunctionalKNN, train, ytrain)
(knn.k, knn.loo_error, count(predict(knn, test) .== ytest))
(7, [0.28, 0.28, 0.24, 0.24, 0.24, 0.24, 0.24], 6)
predict(knn, test; type=:probability)[1:3, :]
3×2 Matrix{Float64}:
 0.571429  0.428571
 0.714286  0.285714
 0.571429  0.428571

Curves reach a common grid as for depth: complete grid data use their own grid, basis data are evaluated on the grid keyword, and irregular or incomplete curves are represented by their FPCA reconstruction (PACE by default, tuned with fpca). New curves are brought to the training representation, with the stored FPCA fit when there is one; complete-grid classifiers need new curves on the training grid. Multivariate functional data use sqrt(Σ_c ‖x_c - y_c‖²) for kNN and the multivariate depths of depth for the depth classifiers.

md = fit(DepthClassifier, train, ytrain; method=ModifiedBandDepth())
dd = fit(DDClassifier, train, ytrain)        # Fraiman–Muniz depths, logistic rule
(count(predict(md, test) .== ytest), count(predict(dd, test) .== ytest))
(8, 8)
predict(dd, test; type=:depth)[1:3, :]       # the DD-plot coordinates
3×2 Matrix{Float64}:
 0.554667  0.413333
 0.745333  0.288
 0.293333  0.529333

The DD-classifier's second stage (classifier) is logistic regression (:glm, the default), Gaussian discriminant analysis of the depths (:lda, :qda), kNN on the depth vectors (:knn) or the degree-one rule of Li, Cuesta-Albertos and Liu (2012) (:dd1, two classes). Training depths include each curve in its own class, as in fda.usc, so with small classes the training depths can separate the classes perfectly; logistic regression then has no finite maximum and the fit throws, while R's glm warns and returns very large coefficients. Use :lda, :qda, :knn or :dd1 in that case.

Random projections are drawn once at fit time and stored on the classifier, so every class and every prediction uses the same directions. Without a bandwidth, ModalDepth uses one bandwidth per class in DepthClassifier (as classif.depth) and the pooled-sample bandwidth for every class in DDClassifier (as classif.DD).

lda = fit(FunctionalLDA, train, ytrain; ncomponents=2)
(lda.settings.fpca_method, lda.priors, count(predict(lda, test) .== ytest))
((:face,), [0.5, 0.5], 8)

Discriminant analysis works on the leading scores of each covariate's FPCA (several covariates are concatenated). As for FPCRegression, complete grid data use FACE by default and irregular or incomplete curves use PACE, whose conditional-expectation scores make sparse curves usable. LDA pools the class covariances with divisor n - G and QDA uses one covariance per class with divisor n_g - 1, as MASS::lda and MASS::qda.

Functional logistic regression

Two-class functional logistic regression is a scalar-on-function GLM and is fitted by the regression models: FPCRegression with family=:binomial (fda.usc fregre.glm on FPC scores) or PenalizedFunctionalRegression with family=:binomial (refund pfr). Code the response as 0 and 1; predict(...; type=:response) returns the probability of class 1.

y01 = Float64.(ytrain .== "high")
logistic = fit(FPCRegression, train, y01; family=:binomial, ncomponents=2)
probability = predict(logistic, test; type=:response)
(round.(probability[1:3]; digits=3), count((probability .> 0.5) .== (ytest .== "high")))
([0.47, 0.691, 0.396], 9)

Reference audit

The implementations follow the sources of fda.usc 2.2.0 (current CRAN) and MASS 7.3-65, read in full for the functions named here.

  • classif.knn calls classif.np with S.KNN. With leave-one-out (cv=TRUE) the diagonal of the distance matrix is set to Inf, the neighbourhood radius is the type-4 quantile at k/n of each row (the k-th smallest distance) and the uniform kernel keeps every curve within it, so curves tied at the radius all count. weights="equal" gives every curve weight one, so probabilities are class shares. The default knn grid is seq(3, min(15, n), by=2); the selected k is the first minimizer of the leave-one-out misclassification. Distances are metric.lp, the trapezoidal L² norm.
  • When classes tie, classif.np and pred2np intend to choose the class of the nearest neighbour but index the distance matrix with class numbers (mdist[ii, ll], nmdist[ii, l]) instead of curve indices, so the tie is resolved by the distance to curves 1, 2, .... This package uses the nearest tied neighbour. The golden fixture has two classes and odd k, so no tie arises.
  • classif.depth computes the depth of every curve with respect to each class (the class's own curves included) and takes which.max. For the random-projection depths it draws 500 directions uniformly on the unit sphere of grid vectors when none are given, while depth.RP itself uses 50 Gaussian-process directions (rproc2fdata); this package uses the latter, whose distribution does not depend on the grid resolution. depth.mode without h takes each class's own 0.15 quantile of distances. Its switch has no branch for the modified band depth, so depth="MB" fails ("number of items to replace ..."), and classif.DD rejects "MB"; here every depth of depth works with both classifiers.
  • classif.DD with depth="mode" first computes the bandwidth of the whole sample and passes it to every class. Its glm rule is classif.glm2boost: one logistic regression of class 2 against class 1 with an intercept and one column per class depth, or one class against the rest for more classes (labels from the smallest probability of "not the class"). R's glm stops when the relative change of the deviance is below 1e-8, which leaves the coefficients about 1e-8 (relative) from the maximum; this package iterates to convergence. lda and qda call MASS with its default prior (class proportions); knn uses Euclidean distances on the depths and the grid seq(3, 19, by=2).
  • The polynomial rule DD1 (MCR0) searches the slopes D₁/D₂ of the training points although its rule compares k·D₁ with D₂, and evaluates its second error term on dep[-ind[, i], 1] with a logical ind, which drops only the first curve instead of selecting the other class. The :dd1 rule here searches the slopes D₂/D₁ that pass through training points and counts the training misclassification directly. DD2, DD3 (random subsets of curves and a smoothed loss) and the gam, np and tree rules are not implemented.
  • classif.lda and classif.qda with weights="equal" average the weights within each class and pass the normalized class averages as prior, so every class gets probability 1/G regardless of its size. The scores come from fdata2model (with basis.x=create.pc.basis(...), the PCA of the discretized curves) and new curves are projected with inprod.fdata after centring with the training mean.

Validation

test/reference/classification_m8.R simulates two-class curves (40 training and 10 new curves on 21 grid points) and three-class curves in the span of sin(kπt), k = 1, 2, 3 (45 and 9 curves), and writes test/data/m8_classification_input.csv and test/data/m8_classification_golden.csv with R 4.5.1, fda.usc 2.2.0 and MASS 7.3-65. Recreate them from the repository root with Rscript test/reference/classification_m8.R. The tests compare, at relative error below 1e-8: classif.knn leave-one-out errors, chosen k, leave-one-out probabilities and new-curve probabilities; classif.depth depths and labels with depth="FM" (FraimanMuniz(integration=:uniform)), "mode" and "RP" (fixed projections); the same rule with the modified band depth (ModifiedBandDepth(), whose trapezoidal weights match fda.usc's internal depth.MB evaluated with respect to each class, since classif.depth has no "MB" branch); classif.DD depths, logistic coefficients (refitted to convergence in the script), fitted and new-curve probabilities, the lda, qda and knn second stages and the pooled modal-depth bandwidth; and classif.lda/classif.qda posterior probabilities for training and new curves, using fpca_options=(; method=:dense) with three components (the curves lie exactly in a three-dimensional space, where discriminant probabilities do not depend on the eigenproblem weights).

FunctionalDataAnalysis.FunctionalKNN — Type
FunctionalKNN
fit(FunctionalKNN, x, y; k=nothing, grid=nothing, fpca=(;))

k-nearest-neighbour classifier for curves with the L² distance (fda.usc 2.2.0 classif.knn). x is GridFunctionalData, IrregularFunctionalData, BasisFunctionalData, MultivariateFunctionalData or an FPCA fit; y holds one label per curve, of any sortable type. The classes are the sorted distinct labels, stored in classes; probability columns follow that order.

Curves reach a common grid as in depth: complete grid data use their grid, basis data are evaluated on grid, and irregular or incomplete curves are represented by an FPCA reconstruction (fit(FPCA, x; method=:pace, fpca...)). Distances use the stored trapezoidal weights, as fda.usc's metric.lp; for multivariate data they are sqrt(Σ_c ‖x_c - y_c‖²).

The neighbours of a curve are the training curves within its k-th smallest distance (ties included, as fda.usc's S.KNN), and the class probabilities are their class shares. The label is the most probable class; ties go to the class of the nearest tied neighbour. fda.usc intends the same tie-break but indexes curves by class number, so its tied labels are arbitrary.

k=nothing chooses k among 3, 5, ..., min(15, n-1) by leave-one-out misclassification, fda.usc's default grid and criterion; a vector of candidates (or one integer) can be given instead. Ties choose the smallest k. fda.usc's grid ends at min(15, n), which can include k = n, more than the n - 1 other curves, when n <= 15. loo_error stores the criterion for every candidate, and fitted returns the leave-one-out labels at the chosen k, as fda.usc's group.est; fitted_probabilities holds their probabilities. Use predict for new curves.

FunctionalDataAnalysis.DepthClassifier — Type
DepthClassifier
fit(DepthClassifier, x, y; method=RandomProjectionDepth(), weights=nothing, grid=nothing, fpca=(;))

Maximum-depth classifier (fda.usc 2.2.0 classif.depth; Cuevas, Febrero and Fraiman, 2007): each curve is assigned to the class in which it is deepest. depths holds the training depths, one column per class in classes order, each computed with depth with respect to that class's curves (a training curve belongs to its own class's reference, as in fda.usc). The first class wins ties, as R's which.max. x, y, grid and fpca are as in FunctionalKNN; method is any depth method of depth and weights its multivariate component weights. Every class needs two curves.

The default RandomProjectionDepth() is fda.usc's default depth ("RP"), with the projections of RandomProjectionDepth (50 Gaussian-process directions, fda.usc depth.RP). Generated projections are drawn once, from the method's rng, and shared by all classes and predictions; the resolved method is stored as method. This departs from classif.depth, which draws 500 directions uniformly on the sphere of grid vectors: those directions depend on the grid resolution, while depth.RP's do not. Supply RandomProjectionDepth(projections=...) to fix the directions. ModalDepth without a bandwidth computes one per class from that class's distances, as classif.depth does; the bandwidths are stored in settings.

fitted returns the training labels (resubstitution, fda.usc's group.est). No class probabilities are defined; predict returns labels or depths.

FunctionalDataAnalysis.DDClassifier — Type
DDClassifier
fit(DDClassifier, x, y; method=FraimanMuniz(), classifier=:glm, k=nothing,
    prior=:proportional, weights=nothing, grid=nothing, fpca=(;))

DD-classifier (Li, Cuesta-Albertos and Liu, 2012; fda.usc 2.2.0 classif.DD): every curve is mapped to its depths with respect to each class (the DD-plot, stored as depths, columns in classes order) and a second classifier works on those depths. x, y, method, weights, grid and fpca are as in DepthClassifier; the defaults method=FraimanMuniz() and classifier=:glm follow fda.usc's (depth="FM", classif="glm"), except that FraimanMuniz() integrates with the stored trapezoidal weights while fda.usc's depth.FM weights grid points equally (see FraimanMuniz); method=FraimanMuniz(integration=:uniform) reproduces classif.DD with depth="FM". Generated random projections are drawn once, and ModalDepth without a bandwidth uses the bandwidth of the pooled training sample for every class, as classif.DD does; the resolved method is stored as method.

classifier selects the second stage, whose fitted quantities are in stage:

  • :glm (default): logistic regression with an intercept on the depths, by maximum likelihood (the IRLS of FPCRegression's binomial family); for more than two classes one class against the rest, as fda.usc. Two-class probabilities are the fitted logistic probabilities; with more classes the one-against-rest probabilities are normalized to sum to one. Classes that the depths separate perfectly make IRLS diverge and throw.
  • :lda, :qda: Gaussian discriminant analysis of the depths with prior (:proportional by default, since classif.DD calls MASS::lda/qda with MASS's default prior).
  • :knn: k nearest neighbours in the Euclidean distance between depth vectors, with k chosen by leave-one-out among 3, 5, ..., min(19, n-1) (the classif.DD default grid) unless k is given; see FunctionalKNN.
  • :dd1: the degree-one DD rule of Li et al. for two classes: class 2 when D₂ > s D₁, with the slope s (0 or a ratio D₂/D₁ of a training curve) minimizing the training misclassification, smallest on ties. No probabilities are defined. fda.usc's MCR0 searches the ratios D₁/D₂ and counts its second error term over all curves but the first (dep[-ind, 1] with a logical ind), so its slopes differ.

fda.usc's polynomial rules of degree two and three (DD2, DD3), which search random subsets of curves with a smoothed loss, and its gam, np and tree rules are not implemented. fitted returns the training labels (resubstitution) and fitted_probabilities their probabilities (nothing for :dd1).

FunctionalDataAnalysis.FunctionalDiscriminant — Type
FunctionalDiscriminant
FunctionalLDA
FunctionalQDA
fit(FunctionalLDA, x, y; fpca=nothing, fpca_options=(;), ncomponents=nothing, prior=:equal)
fit(FunctionalQDA, x, y; fpca=nothing, fpca_options=(;), ncomponents=nothing, prior=:equal)

Functional linear (FunctionalLDA) and quadratic (FunctionalQDA) discriminant analysis on FPC scores, as fda.usc 2.2.0 classif.lda and classif.qda with a principal-component basis (create.pc.basis). Both are FunctionalDiscriminant results. Each class is Gaussian in the leading FPC scores of the covariates; LDA pools the covariance, S = Σ_g Σ_{i∈g} (z_i - m_g)(z_i - m_g)' / (n - G), and QDA estimates one covariance per class with divisor n_g - 1, as R's MASS::lda and MASS::qda. probabilities are the posterior class probabilities, columns in classes order.

x is one univariate functional dataset (grid, irregular or basis), a tuple/vector of them, or MultivariateFunctionalData; scores of several covariates are concatenated. The FPCA follows FPCRegression: each covariate is fitted with fit(FPCA, x_j) defaults, except that complete grid data use method=:face (in the regression study the unsmoothed dense route kept dozens of noise components under FVE(0.99); here they would also make the class covariances singular). Irregular and incomplete curves use PACE, whose conditional-expectation scores make sparse covariates usable. fpca, fpca_options and ncomponents are as in FPCRegression, and settings.fpca_method and settings.fpca_method_source record the routes.

prior=:equal (default) gives every class probability 1/G, which is what fda.usc's classif.lda/classif.qda pass to MASS with their default weights="equal". :proportional uses the class frequencies (MASS's own default), or give a vector of probabilities in classes order.

LDA needs at least K + G curves for K scores and QDA more than K curves in every class; a singular covariance throws (use fewer components). fitted returns the training labels (resubstitution, fda.usc's group.est).
