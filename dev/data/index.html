Data types

Univariate data store complete or masked common grids, curve-specific observations, or exact basis coefficients. Constructors copy observation and coefficient arrays. Basis objects are shared and treated as immutable. eltype(fd) is the numerical scalar type, while iteration yields curves.

julia> using FunctionalDataAnalysis

julia> fd = GridFunctionalData([1 2 3], [0.0, 0.5, 1.0]);

julia> fd[1]
([0.0, 0.5, 1.0], [1.0, 2.0, 3.0])

julia> evaluate(fd, [0.25], PiecewiseLinear())
1×1 Matrix{Float64}:
 1.5

julia> to_grid(to_irregular(fd), fd.grid, NoInterpolation()).values == fd.values
true

Raw data require an explicit evaluator. PiecewiseLinear() returns NaN outside a curve's observed range; to_grid records those results as missing instead. NoInterpolation() requires exact == matches, without a tolerance. During grid conversion it preserves absent observations in the mask and rejects any source time not present in the target grid. All-missing grid rows are representable, but cannot become irregular curves or be fitted.

to_basis is per-curve least squares on the actual observations. It does not estimate a pooled mean, covariance, or bandwidth. Unpenalized fits use pivoted QR; penalized fits use Cholesky and reject singular systems.

Scalar indexing and iteration of basis data retain one-curve basis objects. They never choose a sample grid. Use evaluate(fd[i], t) or to_grid(fd, t) to sample explicitly. Empty subject subsets throw. For basis data, nobs_per_curve reports the number of coefficients, not a chosen grid size.

Multivariate data store copied univariate components for the same subjects. Use component(mfd, j) to select a node; indexing always selects subjects. domain, nobs_per_curve, and sampling_design return results per component. Common-point evaluation returns an n × p × m array and rejects points outside any component domain. A vector of point vectors returns a vector of matrices. Raw components require an evaluator, which basis components ignore. Complete common-grid components also support to_array in FGM order.

Components with a shared floating-point type have an inferable vector constructor. For a type-erased component vector, explicitly supply MultivariateFunctionalData{T}(components) when inference is required. The untyped constructor promotes numerical types across mixed components.

FunctionalDataAnalysis.GridFunctionalData — Type
GridFunctionalData(values, grid; ids=nothing, metadata=(;))

Curves in the rows of a copied n × m matrix on a common, finite, strictly increasing grid with at least two points. At least one curve is required. Missing entries are represented by an observed::Union{Nothing,BitMatrix} mask (true means observed); their stored numerical values are zero. Every nonmissing value must be finite. Integer input becomes Float64. Optional metadata is a deep-copied named tuple of provenance or tuning settings. Subsetting deep-copies this provenance unchanged: selection scores still refer to the original curves and are not recomputed for the subset. Concatenation with vcat preserves equal metadata (deep-copied) and throws ArgumentError when metadata differ. Conversions (to_grid, to_irregular, to_basis) return objects without metadata. Optional ids are copied, unique subject labels of length nobs.

FunctionalDataAnalysis.IrregularFunctionalData — Type
IrregularFunctionalData(times, values; domain=nothing, ties=:error, ids=nothing)
IrregularFunctionalData(times, values, offsets; domain=nothing, ties=:error, ids=nothing)

Copied observations on curve-specific grids. The first form takes vectors of vectors; the second takes concatenated arrays with curve i at offsets[i]:offsets[i+1]-1, starting at 1 and ending at length(times)+1. Every curve has at least one finite observation. Times are sorted within curves. Repeated times throw unless ties=:mean averages their values.

The domain defaults to the range of all times. A supplied finite interval must contain every time; a singleton domain is allowed for point observations. Optional ids are copied, unique subject labels of length nobs.

FunctionalDataAnalysis.BasisFunctionalData — Type
BasisFunctionalData(coefs, basis; ids=nothing, metadata=(;))

Exact functional representations with one coefficient row per curve and nbasis(basis) columns. Coefficients must be finite and at least one curve is required. Coefficients are copied; the basis is shared as an immutable object. Scalar indexing and iteration retain exact one-curve basis objects; they never choose a grid. The object is callable: fd(t) == evaluate(fd, t). Optional metadata is a deep-copied named tuple of provenance or tuning settings. Subsetting deep-copies this provenance unchanged: selection scores still refer to the original curves and are not recomputed for the subset. Concatenation with vcat preserves equal metadata (deep-copied) and throws ArgumentError when metadata differ. Conversions (to_grid, to_irregular, to_basis) return objects without metadata. Optional ids are copied, unique subject labels of length nobs and are retained through subsetting and conversions.

FunctionalDataAnalysis.MultivariateFunctionalData — Type
MultivariateFunctionalData(components)

Copied univariate components (grid, irregular, or basis data) for the same subjects. Components may have different designs and domains. Indexing selects subjects; component(mfd, j) selects node j. Scalar indexing returns each component's own curve representation, including exact basis objects. domain, sampling_design, and nobs_per_curve return one result per component, without aggregating different designs.

FunctionalDataAnalysis.PiecewiseLinear — Type
PiecewiseLinear()

Explicit piecewise-linear interpolation of raw curve observations. Masked grid points are unobserved; interpolation bridges them using the nearest observed points on either side. Values outside each curve's observed range are NaN during evaluation and missing during conversion to a grid. A one-point curve is defined only at that point.

source
FunctionalDataAnalysis.NoInterpolation — Type
NoInterpolation()

Exact lookup of raw observations using ==, with no tolerance. Evaluation throws at unobserved times. Conversion to a grid instead marks absent observations missing and requires every source time in the target grid.

FunctionalDataAnalysis.nobs_per_curve — Function
nobs_per_curve(fd)

Return a Vector{Int} of actual observation counts for raw univariate data. Basis data return the coefficient count per curve, since they have no observation grid. Multivariate data return a Vector{Vector{Int}}, one count vector per component, without aggregating different designs.

FunctionalDataAnalysis.to_array — Function
to_array(mfd)

Return a copied n × p × m array in FunctionalGraphicalModels.jl order: subjects, nodes, grid points. Every component must be complete grid data on the same grid; other representations or missing observations throw.

FunctionalDataAnalysis.to_irregular — Function
to_irregular(fd)
to_irregular(fd::BasisFunctionalData; grid)

Copy grid data to curve-specific observations, dropping only masked points. At least one observation must remain in every curve. Basis data require an explicit grid, where the functions are evaluated exactly. The original domain is retained. Irregular data are copied without changing observations.

source
FunctionalDataAnalysis.to_grid — Function
to_grid(fd, grid, evaluator)
to_grid(fd::BasisFunctionalData, grid)

Copy raw data to a supplied finite increasing grid, using an explicit PiecewiseLinear() or NoInterpolation() evaluator. Piecewise-linear interpolation marks target points outside each curve's observed range as missing, never NaN. Exact conversion marks absent observations missing and requires every source time to appear in the target grid using ==, with no tolerance. Thus a grid → irregular → grid round trip preserves the missing-value mask.

Basis data evaluate exactly on the supplied grid and need no evaluator.

source
FunctionalDataAnalysis.to_basis — Function
to_basis(fd, basis; lambda=0, order=2)

Fit each raw curve by unweighted penalized least squares: sum((y - X*c).^2) + lambda * c' * penalty(basis, order) * c. Use the actual observed times, omitting only masked values. With zero penalty, every curve needs at least nbasis(basis) observations and a full-rank design; pivoted QR solves the fit. Positive finite lambda uses Cholesky and throws if the penalized system is singular. No inverse is formed. Basis data must first be sampled explicitly with to_grid.

Base.getindex — Method
fd[i]
fd[idx]

For grid and irregular data, scalar indexing returns copied (t, y) vectors of actual observations, omitting only masked grid entries. For basis data, it returns a one-curve BasisFunctionalData, preserving the exact basis representation without selecting a grid. Multivariate scalar indexing returns a vector of these component-specific results.

A range, integer vector, or Boolean subject mask returns the same data type, with copied arrays. Empty subsets throw. Indexing always selects subjects; use component(mfd, j) to select a multivariate node.

Base.iterate — Method
iterate(fd[, state])

Iterate over subjects. Grid and irregular data yield copied observation pairs. Basis data yield exact one-curve basis objects. Multivariate data yield a vector containing each component's subject result. No grid or interpolation is chosen for basis data.
